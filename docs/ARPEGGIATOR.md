# 琶音器的通道、按键与踏板约定

本页定义正在开发的多通道琶音器行为；实际交付和验证状态以对应版本记录为准。它扩展已有的升序琶音，不引入新的宿主参数或音色格式。普通 MIDI 通道消息属于各自的通道，参考 [MIDI Association 消息说明](https://midi.org/about-midi-part-3midi-messages)和[控制器表](https://midi.org/midi-1-0-control-change-messages)。重复同音高的处理、排序和 panic 细节是下述 Anyvoc 约定，不声称与 Serum 的算法一致。

## 哪些音符参与琶音

每个输入通道 1–16、音高 0–127 分别保存按键计数、最近一次有效 note-on 的力度和踏板锁存状态。相同通道、相同音高连续收到两次 note-on，必须收到两次匹配的 note-off 才算完全松键；这个组合仍占一个琶音位置。力度采用最近一次 note-on，直到下一次按下或该组合退出候选池。零力度 note-on 视作 note-off；未匹配的 note-off 不减少其他音符或其他通道的计数。

不同通道的同音高各占一个位置。先按音高从低到高排序，同音高按通道从 1 到 16 排序；在当前八度的所有候选演奏完后进入下一八度。超出 MIDI 127 的结果保持为 127，仍保留对应来源通道和力度。生成的 note-on 与 note-off 使用同一个来源通道，所以该通道的弯音、调制轮与控制器复位能作用于生成音符。

候选资料使用固定容量，覆盖全部 16×128 个组合；按键计数采用无符号饱和递增，避免溢出。候选池和时钟是运行时状态，不保存到 `.anyvoc`，恢复音色不会恢复尚未释放的演奏键。

## 踏板与控制器

CC64 踏板状态分别属于每个输入通道，值 64–127 为踩下、0–63 为松开。最后一次匹配松键发生时，只有该通道的踏板能将音符锁存；松开踏板只移除该通道已经松键的锁存。CC64 在琶音器内消费，不能再让声音引擎延长每个生成脉冲，否则短 Gate 会被踏板吞掉。

CC121 重置该通道的踏板并清除锁存，保留仍有按键计数的组合；原消息继续发送给引擎，使该通道的弯音和调制轮复位。它不修改保存的音色参数或其他通道的踏板。候选仍非空时保留琶音时钟；池清空时按下述空池规则复位。

CC120／CC123 在 Anyvoc 中是该通道的停止命令：清除该通道的按键和锁存，保持它的踏板控制器值，并原样传给声音引擎。CC120 硬停止该通道的声部，CC123 让声部按正常 Release 结束；两者都不保留踏板锁存音。这沿用声音引擎的既有约定。当前生成脉冲若属于该通道，立即清除其输出跟踪；其他通道的候选和步进相位继续保留。它们不再额外向通道 1 注入停止消息。

界面 **ALL NOTES OFF／PANIC** 是全局操作，停止所有通道并清除候选、踏板和时钟。它与输入 MIDI 的通道停止消息范围不同。

## 时序与生命周期

每个采样位置先按 MIDI 缓冲的原顺序处理该位置的全部输入，再处理 Gate 结束和新一步的 note-on。同一位置的停止命令后若有新 note-on，该键可重新进入候选；顺序相反时则被停止命令清除。

当普通松键或踏板释放移除一个候选、但池中仍有其他候选时，当前脉冲保持到原 Gate 结束；不会提前截掉这一下。候选全部消失时发送当前生成音符的 note-off，并让声音按正常 Release 结束，下一次有效按键从升序开头立即起步。已有候选继续存在时，池的变化不重置时钟；索引按新的候选数解释。

切换琶音器开关、全局 PANIC、重新准备音频、恢复／切换声音以及宿主从播放变为停止，按既有重置路径清空琶音运行时状态。Poly／Mono／Legato 切换只触发引擎自己的声部切换，保留琶音池与时钟，下一步继续演奏。宿主小节定位、seek 和循环边界锁相仍未实现。

自动验收须使用手工列出的预期生成 MIDI、关闭 ARP 的独立参考处理器，以及实际音频比较；仅把相同输入用两种缓冲渲染只能检查分块一致性，不能证明通道或音符选择正确。外接设备、真人听音和 DAW 工作流另行记录。
