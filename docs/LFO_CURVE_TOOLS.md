# LFO 绘图工具与曲线资产（0.18）

本文件记录 0.18 的实现约定和验收范围。188 组自动回归、pluginval、旧音频对比及限定的独立版原生操作已通过，实际证据与未测项目见 [0.18 验证记录](VALIDATION-0.18.md)。0.17 的交付文件与验证记录保持原样。

Serum 2 的[官方新功能概览第 14 页](https://static.xferrecords.com/Serum%202%20What%27s%20New.pdf)列出独立 X/Y 网格、LFO 绘图编辑和预设。本版在 Anyvoc 既有 LFO Lab 上补充这些操作及选区工具；下面的点数、变换规则和文件格式是 Anyvoc 自己的定义，不代表 Serum 的内部实现或预设兼容性。

## 界面和声音的关系

十个 LFO 分别保留自己的编辑模式、网格、吸附与选区。TOOLS 展开下半区的绘图工具，曲线和底部琴键继续可见。选择网格、切换 Draw/Select、改变选区和预设变换数值都只是编辑器操作，不改变声音、不生成声音撤销记录。这些编辑设置不属于宿主自动化参数，也不写入音色格式；关闭编辑器后不保证恢复。

实际声音仍由原有的 33 个等距点和 Linear/Step 插值决定。1,192 个宿主参数、顺序、范围和 schema 13 均不变。点、插值及 Custom 选择保存在原有音色状态中，旧音色无需新增字段。

点值保留旧参数的 **0.01 步长**。工具先计算网格或变换结果，再由声音参数量化；例如 Y 的 16 等分目标 0.125，实际点值保存为 0.13。精确输入也服从此步长，不承诺任意小数都能原样进入声音状态。独立曲线文件可保留 float 数值，但导入到这版合成器时仍按同一参数精度取整。

普通周期波形开始编辑时，取其 33 个可见点作为起始曲线；Random 没有固定可见周期，工具操作其保存的 Custom 点，必须在界面说明。Chaos 不允许画图、点编辑或曲线替换；切回可编辑形状后，原有曲线值仍保留。只复制或保存曲线不切换声音形状。

## 网格与选区

横纵网格分别支持 1、2、4、8、16、32 等分，各有独立吸附开关。网格细密程度不增加真实控制点。X 吸附选择最近的 `32 / 等分数` 点间隔；Y 在 −1 到 +1 之间等分。精确半格取较大坐标，即 X 向右、Y 向 +1。关闭对应吸附时保留原始自由绘制行为。

Select 模式拖动得到含首尾点的选区；默认选择全部 33 点，All 可恢复全选。Flip X 反转选区的点顺序，Flip Y 将选区值取负。所有选区操作保持选区外的点逐值不变。

选区位移和缩放使用固定选区边界。对目标点 `i`，读取原曲线的位置为 `中心 + (i - 中心 - X位移) / 宽度倍率`，超出选区时保持最近端点，按原 Linear/Step 插值采样，再乘高度倍率、加 Y 位移并限制在 −1 到 +1。X 位移单位为一个真实点间隔，范围 −32 到 +32，宽度范围 0.25–4、高度范围 0–4；Y 位移范围 −2 到 +2。单点选区仍可调整幅度。变换数值先暂存，按 APPLY 才提交；界面说明端点保持和限幅规则。

精确点编辑使用 1–33 的点编号与 −1 到 +1 数值。一个完成的笔画、一次 Flip、一次 APPLY、一次 SET 或一次成功粘贴／加载对应一次声音撤销；无变化的操作不增加历史。重复应用变换以当时的曲线为输入。Escape 停止当前手势，撤销已绘内容使用 UNDO。

## 曲线文件与复制

`.anycurve` 仅保存完整 33 个点和 Linear/Step 插值，不包含振荡器、路由、速度、相位、播放模式、实时轨迹、网格或选区。加载它会替换当前 LFO 的整条 Custom 曲线；其他 LFO 与调制设置保持不变。它不是完整的 `.anyvoc` 音色，也不是 Serum 曲线预设。

Paste／Load 是明确的曲线替换：当前为基础波形或 Random 时，即使其可见／保存的 33 点与文件相同，也切为 Custom，整次操作可撤销。当前已是 Custom 且参数量化后完全相同，则不新增撤销。相比之下，Flip／SET／APPLY 没有造成点或插值变化时保留原声音形状；基础 Sine 的连续函数与 33 点插值曲线不能被视为同一声音算法。

格式是最多 16 KiB 的严格 ASCII XML 子集：根元素 `ANYVOC_LFO_CURVE`，属性 `schema="1"` 与 `interpolation="0"` 或 `"1"`，恰好 33 个顺序排列的 `POINT value="有限数值"` 子元素。数值须在 −1 到 +1；未知属性／子元素、缺项、重复、非有限值、超长内容、非 ASCII 字符、BOM、注释、处理指令、DTD／实体及尾部垃圾均拒绝。可省略 XML 声明；若有声明，只接受位于文件字节 0 的 `<?xml version="1.0" encoding="UTF-8"?>`。解析失败保留原声音和输出数据；保存用临时文件替换，写入失败不能损坏原目标文件。

Copy/Paste 使用相同文本格式。加载文件选择器打开后，如果对应声音、LFO 页面、历史版本或编辑器生命周期发生变化，迟到的选择结果不得覆盖新状态。取消不改声音。所有音色写入仍经过正常宿主手势与声音历史，而不直接修改音频线程状态。

## 验收目标

- 以独立数值例子核对半格吸附、选区反转、线性／阶梯重采样、端点保持、限幅、身份变换及非法输入原子拒绝。
- 十个 LFO 的真实控件接线和彼此隔离；仅查看／选择／复制不改声音；实际编辑、撤销、重做和音色保存重开保持结果。
- 宿主在手势开始、值回调或结束时修改相关参数、替换状态、换页或销毁编辑器后，不再写过期值，所有开始的手势均结束。
- 文件成功往返、损坏／超大内容拒绝、保存失败及异步选择取消／过期；测试使用可控平台依赖验证操作链，原生文件对话框和系统剪贴板另行记录。
- 旧演示与修改前 0.17 的留存测试程序重新渲染结果逐字节比较；既有 DSP 回归继续通过。
- 标准和最小窗口检查工具布局、选区反馈与琴键可见性，并用一个实际音色展示组合编辑。

0.18 完成状态、实际测试数量与发布包结果以本轮最终验证记录为准。
