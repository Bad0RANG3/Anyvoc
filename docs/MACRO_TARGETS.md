# 宏作为调制目标（0.19 计算与兼容约定）

本页记录 0.19 已实现的计算与兼容约定。本机自动测试、音频、限定范围原生操作和发行包校验见 [0.19 验证记录](VALIDATION-0.19.md)；云端 CI 与 DAW 实测另行记录，不从本页推定通过。0.18 的发行包、验证报告和 GitHub 提交保留为基线。

Serum 2 的[官方新功能概览第 14 页](https://static.xferrecords.com/Serum%202%20What%27s%20New.pdf)列出八个宏可作为调制目标。本版实现这一调音流程；下面的复音、延迟、限幅和反馈规则是 Anyvoc 的明确定义，不声称复现未公开的 Serum DSP。

## 基础值、有效值与反馈

宏的旋钮和宿主自动化继续控制全局 **0–1 基础值**，使用既有 15 ms 平滑。每个活动声部独立保存八个宏的上一采样入量，因此力度、包络和 Trigger LFO 可以让和弦中的每个音拥有不同的有效宏值。

对声部 `v`、宏 `k`、采样 `n`：

```text
effective[v,k,n] = clamp(baseSmoothed[k,n] + incoming[v,k,n-1], 0, 1)
incoming[v,k,n] = sum(指向宏 k 的各条有效路由本采样输出)
```

每采样先同时计算全部八个有效值；所有路由的主来源和 AUX 都读取同一份值，再统一写回下一采样的入量。主来源／AUX 的极性、曲率、相乘及 Amount 规则与原矩阵相同。自调制和相互调制均有明确的一采样反馈延迟，不递归求解，不因矩阵上下排列形成不同拓扑。

没有有效入路的宏直接使用平滑基础值并清除旧入量。旁通、Off 或目标量与当前平滑量都为零的路由不是有效入路；删除最后一条入路时不会再消费其遗留的一采样结果。一般 Amount 变动仍按既有平滑规则逐渐到达目标。每个宏的有效值限制在 0–1，反馈可能产生快速变化，不承诺自动抑制高频或混叠。

新声部、抢音、Mono retrigger、PANIC/reset 清空宏入量。Mono legato、踏板保持及 release 继续沿用当前声部状态，直到 Amp 包络结束；All Notes Off 遵循释放规则，All Sound Off 立即清除。

宏入量每个音频采样计算；所有受调宏都视为可能包含快速变化，主来源及 AUX 的依赖继续跨宏和 LFO 相位目标传播。受影响的音高、声像、滤波和 Warp 控制按采样更新，不能因经由宏而降回原 16 样本控制间隔。退出这条路径时刷新相关缓存，避免遗留最后一个调制值。

## 行顺序与兼容

旧目标 0–27 和所有旧来源 ID 保持原义，新增 Macro 1–8 为目标 28–35。旧 LFO Phase 的边界仍是 18–27，不随目标总数扩展。

完整保留 0.18 的前 1,192 个宿主参数定义和顺序；在末尾为 32 条路由分别追加 `MacroEnabled`（默认 false）与 `MacroTarget`（Macro 1–8，默认 Macro 1），共 **1,256 个参数**，新增 VersionHint 14。有效目标优先级为 Macro → LFO Phase → Warp → Filter → Original；切回旧目标关闭 MacroEnabled，记忆的其他选择器值保留。分配空行和清空会处理完整 19 字段，重排／撤销不得遗漏隐藏选择器。重复投放已有来源／目标组合会重新启用该路由，不复制成新行；独立的路由复制操作仍待后续实现。

状态升级为 schema 14，读取 1–13 时为缺失宏目标参数补默认值；当前 schema 缺字段、重复或非法数据须拒绝。新版音色应另存，不能假定旧程序可读取新格式。旧 26 个工厂音色保留顺序，末尾新增 Performance / Prism Handle 和 Motion / Breathing Prism。

含有效宏图的**纯行置换**按完整 32 行配置多重集辨认，路由平滑量跟随同一配置迁移；宏影响到的目标采用规范顺序累加。目标是宏及其下游图在 Amount 尚在平滑时交换显示位置也得到一致输出。一般同时改变来源、目标或深度不属于纯置换，继续使用原槽位平滑，不承诺与未编辑声音相同。没有新宏图时保留旧矩阵的运算顺序和行为；与宏无关的旧目标也保留原浮点累加顺序，因此不宣称这些无关路由自身换行后逐位相同。

这里的置换保证以引擎收到完整的前后路由配置为条件。处理器目前逐参数发布多字段编辑；若音频回调恰好读到一次行移动的中间状态，可能按一般编辑处理。自动测试覆盖完整移动后渲染以及引擎完整快照的平滑迁移，未证明实时并发移动中的每个音频块都逐位不变。音频侧整组路由发布仍是后续工作。

## 界面

八个宏旋钮都可接受来源拖放，并支持外圈、路由菜单和矩阵目标选择。旋钮读数始终是可编辑基础值，不能用实时有效值反写参数或生成撤销历史。EV 只读显示引擎最近一次实际读取的有效值，注明 latest voice；多声部时选最新活动声部，不表示全局或所有音符的平均值。无活动声部时显示 idle base。八个读数使用同一份一致快照。

状态载入或 PANIC 已请求但音频回调尚未执行时，界面先显示当前参数基础值及 idle base，避免沿用上一音色的声部。换宏组、隐藏页面、宿主重入和关闭编辑器必须终止过期编辑并平衡宿主手势。

## 本轮验收要求

- 以独立手算序列检验基础值加前一采样入量、上下限、正负深度、自反馈、双向反馈及主源／AUX 同快照。
- 检验复音隔离、最新活动声部显示、idle/reset、抢音、mono retrigger 与 legato、踏板与释放、不同采样率及音频块划分。
- 新宏目标全八项、首末路由、32 行全满、隐藏选择器、重复投放、清空、纯行移动、Undo/Redo、保存恢复和 schema 1–13 迁移；宿主 begin/value/end 重入与销毁后无迟到写入。
- 高频 LFO → 宏 → 声音目标、AUX 经过宏及宏／LFO 相位闭环有真实输出证据；旧 0.18 测试 EXE 新渲染的旧演示与新版比较。
- 正常与最小窗口查看基础值／EV、拖放／外圈及两个宏组；自动控件测试和真实 Windows 操作分别记录。
- 完整构建、四套回归、pluginval、对比音频、文档及打包完整性校验；未实测项目明示保留。

更多声源、滤波和效果调制目标仍属于 P1C 后续工作；本轮不会因加入宏目标就宣称整个路线图或 Serum 2 等价已完成。
