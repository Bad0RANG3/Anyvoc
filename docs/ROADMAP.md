# Anyvoc 路线图

更新：2026-11-18。当前源码为 **0.18.0，Windows x64 独立版与 VST3**；P1B 绘图工具的实现、本轮验证与发行包核验已完成，**当前约定范围已交付，本地 0.18 包可用，0.18 云端 CI 未执行**。0.17 的 P1A 历史源码、本机验收及发行包证据继续保留。0.17 提交 `f20c1aa` 的云端干净构建及四套共 175 组测试见[独立云端证据](GITHUB_CI-0.17.md)，0.16.0 继续保留为历史基线。

目标是做出能用于完整音色设计、演奏、保存和 DAW 工程制作的原创合成器，优先照顾初学者的调音体验。Serum 2 的工作流程是功能参照，不是已经达到的产品等价标准；Anyvoc 不支持 Serum 预设，也没有证明声音、算法或功能与其相同。

本文件记录优先级、依赖和验收条件，不承诺日期。P0 的源码与文档基线已有证据，P1A、P1B 当前约定范围已交付；P1C 及其余未标明实现的阶段仍是计划。接口约定、草稿代码或演示画面不等于已交付功能；每个阶段只有在对应版本的验证记录和发行包齐备后才能标为交付完成。

## 0.16 历史基线与 0.17／0.18 交付

以下表格记录 [0.16 验证归档](VALIDATION-0.16.md)对应的历史基线，不能将它的验证范围直接延伸到后续版本：

| 范围 | 已有能力 | 仍需区分的边界 |
| --- | --- | --- |
| 调制 | 10 个 LFO、4 个包络、8 个宏；32 条路由，主源/AUX 极性与曲率、旁通、排序、撤销 | 宏目前仅作来源；0.16 不包含 Chaos，更多目标尚未实现 |
| LFO 与包络编辑 | 33 点曲线；相位、方向、Swing、独立 20–1000 Hz；DAHDSR、曲率、BPM、逐包络连奏重触发 | 高速调制不等于全面抗混叠；没有全部绘图工具 |
| 声音与使用流程 | 波表、采样、颗粒合成；滤波、Warp、基础效果、音色库、保存和撤销；24 个工厂音色 | 多采样/SFZ、频谱声源、效果总线、Clip、MPE 等未完成 |
| 验证与交付 | 162 组测试通过，pluginval strictness 5 通过；旧版音频一致性、对比音频、74 张预览及独立版原生操作记录 | pluginval 不替代 DAW 实测；FL Studio 和其他 DAW 尚未验证，AU/AAX/macOS 未提供 |

0.17 在这条基线上增加十个 LFO 的 Lorenz／Rössler 模式，升级为 schema 13、1,192 个参数、26 个工厂音色。最终 [四套全量测试](ctest-0.17.txt)共 **175 组（61／98／10／6）全部通过，用时 135.03 秒**，其中 Processor 129.80 秒；[详细记录](test-details-0.17.txt)、[pluginval strictness 5](pluginval-0.17.txt)（随机种子 `0x5f5ab2b`）与[独立音频分析](audio-analysis-0.17.json)均有通过证据，旧演示与 0.16 参照逐字节相同。已生成 80 张预览，新增 6 张逐一检查未见裁切；新 20 秒演示受控对比 Lorenz／Rössler，最终重渲染的 PCM 哈希保持不变。原生操作已完成下述限定范围，发行包完整性校验通过，**P1A 当前约定范围交付完成。**

0.18 在不改变生产 DSP、schema 13、1,192 参数和 26 个工厂音色的前提下补充绘图工具与独立曲线资产。当前 [四套测试](ctest-0.18.txt)共 **188 组（68／104／10／6）通过，用时 161.94 秒**，[pluginval strictness 5](pluginval-0.18.txt)（随机种子 `0x4fc4b12`）通过。旧演示与留存 0.17 程序新渲染的结果逐字节相同，Motion／Chaos 现版重渲染也与旧文件相同。84 张预览已生成，新增 4 张工具页／选区页逐一检查无裁切；原生曲线保存、载入、撤销与最小窗口检查已完成下述范围。**Windows 包 208 个文件、完整源码包 4,600 个文件校验通过，P1B 当前约定范围已交付；0.18 尚未执行云端 CI。**

目前优先使用独立版。FL Studio 的系统插件目录安装曾需要用户确认 Windows 管理员权限，因此不能把“已生成 VST3”写成“已在 FL Studio 完整可用”。原生 Ctrl 组合键确认、间歇性琶音持续音 RMS 问题、采样/颗粒变调及非线性混叠等边界继续保留在验证报告中，不能因增加功能而自动视为解决。

功能范围参考 Xfer 的 [Serum 2 官方新功能概览](https://static.xferrecords.com/Serum%202%20What%27s%20New.pdf)：第 14–15 页介绍调制与矩阵，第 6–9 页介绍声源，第 10–13、16 页介绍滤波和效果路由，第 17–20 页介绍序列与浏览器。它用于确认用户工作流程的覆盖范围，不公开具体 DSP 实现。下面的实现方式、测试和通过标准是 Anyvoc 自己的计划。

## P1：完成调制设计的主要缺口

### 1A. Chaos LFO：Lorenz 与 Rössler

**状态：0.17 当前约定范围交付完成。** 最终自动化／pluginval／音频、限定范围的原生操作检查及 Windows／源码包校验已完成；本轮不再扩充功能。0.16 的功能清单仍不包含 Chaos。

**本轮实现：** 十个 LFO 已增加真实 Lorenz／Rössler 方程积分，采用每名义周期 128 步 RK4 与 Hermite 插值。主卡与 Lab 使用同一波形入口，动态图形读取实际 DSP 的一致 XYZ 快照，速度表示演化推进量。Chaos 下禁用没有定义的 Phase、Direction、相位拖放和 Custom 绘图，保留旧值；背后的旧波形时钟继续推进，切回按原规则读取。固定初态、Free／Trigger／Envelope、Mono／Legato、Swing 与模式切换的定义见 [Chaos 文档](CHAOS_LFO.md)。

**已实现的兼容方式：** 在原 1,182 个参数后追加十个默认 Off 的 `lfoNChaos`（Off / Lorenz / Rossler），总数 1,192；原 Shape、Kind 选项索引不变，有效 UI 波形增加两项，状态版本为 schema 13。旧状态迁移补默认 Off。曲线操作的相关参数快照由 45 项扩至 46 项。工厂音色新增 Butterfly Current、Spiral Drift，总数 26。

**已有验证：** [Engine 61 组](engine-0.17.txt)覆盖独立细网格方程参考、全部十个初态的长期有界性、不同采样率、生命周期、主源／AUX／高速相位链实际音频与相干快照；[最终四套测试](ctest-0.17.txt)全部通过，Processor 为 98 组。最终模块通过 [pluginval strictness 5](pluginval-0.17.txt)；[独立音频报告](audio-analysis-0.17.json)确认旧演示逐字节一致，并分析同 MIDI、同速度、同增益的 20 秒 Lorenz／Rössler 对比。静态预览共生成 80 张并逐张检查新增 6 张；原生操作另有下述记录。

**原生检查范围：** 鼠标选择 Butterfly Current，两种 Chaos 的屏幕 C4 演奏均有绿色电平；Rössler 演奏后撤销回 Lorenz 清零且没有错误连线。Chaos 下 Phase 拖动后仍为 0，Speed 1.80→7.29→撤销回 1.80；Free 持续演化，Envelope 短音后 XYZ 稳定；切回 Sine 恢复控件后再撤销，最小窗口检查完成。退出后恢复原设置并核对 SHA。Envelope 原生观察没有测量整名义周期；本轮没有真人听音、原生保存／加载重测或 DAW 验收，文字搜索因 CUA 未能传递输入而未验证。详见 [本机验证记录](VALIDATION-0.17.md)。

**性能边界：** [8 种情形的基准](benchmark-chaos-0.17.txt)记录了常用与极端负载。16 声部、10 个 1,000 Hz Trigger 的墙钟／音频时长为 Lorenz 0.605183、Rössler 0.599409；无路由 Rössler 为 0.549767，当前仍继续积分，未实现按需求停算。测量来自指定机器上的简单音色离线平均值，不承诺实时无掉音；模型、配置与全表见 [Chaos 文档](CHAOS_LFO.md)。

**发行包与边界：** Windows 包 190 个文件、完整源码包 4,580 个文件，CRC、安全唯一路径、精确集合和逐文件字节一致性校验通过；构建与包内 EXE／VST3 的版本均为 0.17.0，二进制哈希匹配最终构建。`Anyvoc-0.17.0-PackageVerification.json` 外置于发行包目录，详见 [0.17 验证记录](VALIDATION-0.17.md)。真人听音、原生保存／加载和文字搜索重测、DAW 实测仍未覆盖。0.17 云端 CI 后续已通过并另行归档，不代替这些未测项目。

### 1B. LFO 绘图工具与曲线资产

**状态：0.18 当前约定范围已交付。** 本机测试、pluginval、旧声音对比、工具预览、下述原生操作及 Windows／完整源码包核验已有证据，本地包可用；0.18 云端 CI 尚未执行，不能沿用 0.17 的绿色结果。

**已实现：** LFO Lab 的 TOOLS 保留画布和底部琴键，提供 Draw／Select、独立 X/Y 网格与吸附、含两端点的选区、Flip X/Y、暂存位移／宽高缩放后 APPLY、单点数值 SET，以及跨 LFO／实例复制粘贴和独立 `.anycurve` 保存／载入。工具沿用 33 点与原参数 0.01 精度，不增加声音参数或改变 DSP。网格、选区、暂存值等是每个 LFO 独立的界面状态，不写入音色或工程；COPY／SAVE 本身不改声音。工具及边界见 [使用手册](USER_GUIDE.md)与[曲线工具说明](LFO_CURVE_TOOLS.md)。

**资产与兼容约定：** `.anycurve` 是最多 16 KiB 的严格独立 XML，只含 33 点及 Linear／Step 插值。无效载入保留声音。Paste／Load 显式选择 Custom，即使基础波形／Random 的采样点或保存点相同也形成一次可撤销编辑；已 Custom 时重复相同实际数据没有新撤销。Flip／SET／APPLY 的无变化操作保持原形状。基础波形工具以可见采样点开始，Random 使用保存的 Custom 曲线，Chaos 禁用曲线编辑并保留旧值。更多节点、公式或不同曲线表示仍需另行定义，不能把网格变密当作新增控制点。

**自动与静态验证：** [最终 188 组测试](ctest-0.18.txt)和[详细日志](test-details-0.18.txt)涵盖独立数值期望、选区外不变、0.01 量化、单次撤销、状态保存与恢复、所有相关参数变动、回调中销毁／隐藏、旧手势结束及异步文件返回等边界；剪贴板／文件返回自动测试通过可替换的平台服务运行。最终 VST3 通过 [pluginval](pluginval-0.18.txt)，[旧声音对比](audio-analysis-0.18.json)及[源码兼容核对](source-compatibility-0.18.json)保留参照。共生成 84 张预览，新增工具与选区各两种尺寸的 4 张已逐一检查；Painted Steps 组合编辑示例写入使用手册。

**原生检查与未测项：** 从 Neon Skyline 打开工具，经原生保存对话框生成 `Native18-Sine.anycurve`（独立解析 33 点、1,121 字节）；拖选 9–25 点、Flip Y、一次 Undo 复原。通过原生载入对话框读取该曲线，返回控制页确认 Custom，屏幕 C4 有绿色电平，Undo 回 Sine；另检查 LOAD 后 Escape 取消保持，以及实际最小窗口工具和键盘无裁切。退出后恢复原设置并核对 SHA。原生操作系统剪贴板、外接 MIDI、真人听音、DAW，以及整音色原生保存重开本轮未测；曲线文件检查不能代替完整音色保存重开。详情见 [0.18 验证记录](VALIDATION-0.18.md)。

**发行包与后续验证：** Windows 包 208 个文件、完整源码包 4,600 个文件，CRC、安全唯一路径、精确集合及逐文件内容校验通过；包内 EXE／VST3 为 0.18.0，与本轮构建哈希一致。`dist/Anyvoc-0.18.0-PackageVerification.json` 外置于 ZIP；本地独立版入口为 `dist/Anyvoc-0.18.0-Windows/Anyvoc.exe`。后续单独记录本版本云端构建结果，保留上述原生未测项，不将已有自动测试等同于这些检查。

## P2：扩展真实可用的声源

### 2A. 多采样与 SFZ

**具体工作：** 键区、力度层、根音、音量/调音、循环与交叉渐变；提供可查看映射的编辑页和缺失资源提示。先公布支持的 SFZ 指令子集，之后逐项扩大；不以能打开扩展名宣称完整 SFZ 兼容。

**依赖：** 资源管理、音频线程之外的文件读取/解码、内存上限、路径重定位和工程自包含策略。大样本或流式加载先做资源预算；当前 20 秒导入限制不能直接当作多采样方案。

**验收与证据：** 公开或自制且有使用许可的最小样本集；键区/力度边界、循环衔接、缺文件、损坏文件、超额资源、重开与迁移测试。录制跨键区和力度层的 MIDI 对比，标明采样率、内存峰值及是否存在流式读取。第三方 SFZ 兼容性按文件和指令清单记录。

### 2B. 频谱声源与现有声源质量

**具体工作：** 分析/重合成、独立时间与音高控制、频谱扫描与频带编辑；同时改善采样/颗粒变调的可听问题。波表补充更完整的编辑、公式和转换能力，所有导入失败都保留原声音。

**依赖：** 离线分析缓存、重采样与窗函数方案、相位连续性、延迟/资源上限和可撤销的资源快照。先说明哪些调整实时完成，哪些需要预处理。

**验收与证据：** 正弦、脉冲、噪声与短素材的独立分析参考；重合成误差、时间/音高独立性、边界爆音和有限值测试。提供同电平对比、CPU/内存/延迟报告；工程重开恢复相同素材和设置。不能仅用频谱动画作为验收。

## P3：完成混音与演奏工作流程

### 3A. 效果总线与可重排效果链

**具体工作：** 声源/滤波送入独立效果总线、直达与发送量；效果实例可重排、旁通、复制和保存链预设。按基础需求扩充效果类型，后续再做分频、Mid/Side 和卷积等模块。

**依赖：** 明确路由图、允许的反馈、增益规则、尾音、延迟补偿与实时安全的图切换；保存格式必须能表达每个实例的独立状态。

**验收与证据：** 用脉冲和参考信号核对每条路由的增益/延迟；旁通、重排与加载过程无非法输出，尾音和 PANIC 行为明确。参数自动化、撤销、工程恢复和多实例隔离通过。记录高负载下的 CPU、内存及爆音检查，不以效果数量作为完成标准。

### 3B. Clip、琶音与 MIDI 演奏

**具体工作：** Clip 音符编辑、循环、录入、局部自动化和可保存片段；扩展琶音图案、力度、概率、重触发与 MIDI 输出。支持与独立版时钟和 DAW 传输一致的开始、停止及定位。

**依赖：** 统一音符所有权、时间线调度、采样精度的事件边界、宿主 seek/loop 行为和 MIDI 输出能力。先复现并处理现有间歇性琶音持续音问题。

**验收与证据：** 固定 MIDI 事件序列参考；不同块大小、BPM 改变、停止/跳转/循环、踏板与快速开关模式不丢 note-off 或产生卡音。概率测试使用可复现种子。独立版及实际 DAW 各保存一个可重开的工程/片段，并对照录音与事件日志。

### 3C. MPE 与表达控制

**具体工作：** 按音符的音高、压力和音色控制；直观的映射与范围设置，保持普通 MIDI 使用方式。

**依赖：** 每音符通道/身份管理、分配与抢音策略、弯音范围、踏板和单音/连奏规则。先定义同音重复、通道重用和区域设置的行为。

**验收与证据：** 合成 MIDI 测试与真实控制器/DAW 输入分别记录；和弦中只改变目标音符，释放或抢音后不串扰。保存重开保留配置；普通 MIDI 与旧音色回归通过。没有硬件实测时明确标记该项待验证。

## P4：音质、效率和滤波深度

**具体工作：** 扩充滤波类型与非线性模型，完善高共振/快速调制行为；评估 Warp、失真和高速调制的抗混叠、过采样及质量档位；改善密集复音、颗粒和复杂矩阵的处理效率。

**依赖：** 统一测试信号、频谱分析、最坏负载场景与目标机器记录；每个质量模式先约定延迟、CPU 和旧预设的兼容方式。可靠性和性能测量从 P1 起随版本执行，这一阶段用于系统性扩展，不是推迟修复严重问题。

**验收与证据：** 滤波器频响/脉冲/稳定性参考；多个采样率下的混叠频谱、瞬态与电平对比；44.1/48/96 kHz、不同 buffer、最大复音与路由负载的实测。报告改进量和代价，不只写“更高音质”。新增质量模式关闭时保持约定的旧行为；延迟向宿主正确报告。

## P5：DAW 与平台交付

**具体工作：** 首先完成 Windows FL Studio 的扫描、加载、MIDI、自动化、保存/重开、冻结/导出、多实例与卸载验证；随后按用户实际使用的 Windows VST3 宿主逐个扩展。macOS VST3/AU 和 AAX 分别立项，建立对应构建、安装和验证流程。

**依赖：** 可使用的 DAW 版本、安装路径和必要权限；macOS 测试设备与签名流程，AAX 对应开发工具和宿主环境。当前用户选择独立版，因此这些条件未满足时保留“待实测”，不阻塞独立版修复与调音功能。

**验收与证据：** 每个宿主单独记录系统/宿主/插件版本、测试步骤、结果和失败项。自动化映射与旧工程不漂移；保存含外部素材的工程后移动原素材仍按既定策略恢复；离线和实时输出在约定误差内一致。安装、更新与回退不破坏用户设置。pluginval 或某一个宿主通过不能扩写为“兼容所有 DAW”。

## P6：初学者、音色库和无障碍体验

**具体工作：** 中文说明与可选中文界面；清晰的参数单位、不可用原因和调制路径；可检索的作者/标签/版本元数据、更多原创示例音色和教程。支持完整键盘导航、明确焦点、可读的辅助技术名称、高对比与合理缩放。

**依赖：** 稳定的参数命名与资源格式、翻译文本体系、键盘与辅助技术的实际测试环境。每次新增控件立即补齐名称、提示和最小尺寸检查；整体完善在此阶段验收。

**验收与证据：** 初学者能按文档完成“打开—选音色—弹奏—分配调制—撤销—保存—重开”；键盘可触达并操作核心流程；验证 Windows 组合键的实际送达，不能只引用处理函数单测。中文与英文、标准与最小窗口/DPI 下无截断，禁用理由可理解。库损坏、缺资源和版本不支持时给出可执行的恢复提示。

## 每次交付共同的完成条件

1. 实现与文档描述一致；新功能有明确默认值、参数映射、迁移及撤销规则，保留旧数据样本。
2. 有针对新增行为的独立数值/音频参考；相关回归、宿主重入和编辑器销毁测试通过。修正测试夹具时解释依据，不以放宽断言掩盖实际问题。
3. 在标准与最小尺寸检查可操作性；原生界面验证与无窗口自动测试分别记录，未做的检查直接写明。
4. 记录音频设置、有限值、峰值、CPU/内存、已知风险及试听是否实际完成；数值差异不等同于主观音质结论。
5. `VALIDATION.md` 指向本次实际日志、音频和预览；打包后的文件/版本/哈希复核完成，源码与发行包可追溯。
6. 更新路线图状态时关联对应版本和证据。未通过的验收项继续列为未完成；没有乐观日期或“已达到 Serum 2”这类未经证明的结论。
