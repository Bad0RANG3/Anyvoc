# Anyvoc 当前状态

核对日期：2026-11-18。当前版本为 **0.19.0，Windows x64 独立版与 VST3**。八个宏作为调制目标已实现，完整自动测试、独立音频分析和限定范围原生检查已通过；界面文字修正后的补测、预览复核与发行包校验也已完成。本机 0.19 包可用，[本版 bf3efc6 云端构建与 201 组测试](GITHUB_CI-0.19.md)也已通过；已交付的 0.18 包继续保留，[0.18 云端构建与 188 组测试](GITHUB_CI-0.18.md)已通过。

Anyvoc 能独立运行、演奏、调音和保存音色。当前按用户选择优先完善独立版的界面与调音体验。**完整 Serum 2 同等功能与声音目标尚未实现**；Anyvoc 使用自己的界面、DSP 和状态格式，不支持 Serum 预设。Windows VST3 已生成，FL Studio 和其他 DAW 仍须分别实测。

## 功能矩阵

“已完成”仅表示该行列出的范围已实现并有验证；“部分完成”表示有可用实现，但仍缺少相关能力；“未实现”不包含仅有设计的内容；“未验证”表示尚无足够的实际使用证据。

| 独立版演奏与编辑 | 已完成本轮检查范围 | 0.19 原生检查两组宏拖放、base/EV、外圈撤销、最小窗口及宏音色 SAVE→INIT→LOAD；不涵盖程序重启或外部素材恢复。本轮未测外接 MIDI，设备与驱动组合未全面覆盖。 |

| 声源与复音 | 部分完成 | 三个振荡器可使用波表、采样或颗粒模式，另有 Sub 和 Noise；支持 16 复音、1–7 路 Unison。没有多采样键区映射、SFZ 或频谱振荡器。 |

| Warp 与振荡器间调制 | 部分完成 | 双 Warp 槽，Bend+/−、Pulse Width、Sync、Mirror、Fold，以及 FM／PM／AM／RM。算法与路由范围有限，未实现完整的过采样抗混叠方案。 |

| 十个 LFO | 已完成当前范围 | 正弦、三角、锯齿、方波、Random 和 33 点 Custom；速度／节拍、Free／Trigger／Envelope、线性／阶梯插值、Phase、Forward／Reverse／Ping Pong、Swing 跟随和 20–1,000 Hz Audio Rate。Random 保留自身序列，Phase／Direction 对它不生效。 |

| 效果 | 部分完成 | Drive、Chorus、Delay、Reverb 可用；尚无完整的多总线效果架构及更多效果种类。 |

## 下一步及已知边界

1. 完成 P1C 剩余工作：音频侧整组路由发布、独立路由复制，以及更多声源、滤波和效果目标。现有纯置换测试以完整配置快照为条件，不能宣称实时移动时每个中间块都逐位不变。
2. 复核原生组合键与间歇性琶音/踏板持续音问题；进一步测量多声部、复杂曲率、颗粒和高 Unison 的实时回调耗时。离线性能均值不保证实时无掉音。
3. 按依赖逐步增加多采样/SFZ、频谱声源、效果总线、Clip 与 MPE，详见 [路线图](ROADMAP.md)。
4. 用户需要 DAW 时首先实测 FL Studio 的扫描、演奏、自动化与保存重开，再逐宿主扩展；不以 pluginval 代替宿主验收。

高频反馈、Warp 等非线性处理和采样/颗粒变调仍有混叠边界。当前没有完整中文界面、无障碍验收、系统剪贴板原生验收、外接 MIDI、真人听音或跨 DAW 验收。本轮保存载入仅覆盖上述宏示例音色，不能扩写为所有外部素材、程序重启和工程恢复均已验证。
