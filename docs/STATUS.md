# Anyvoc 当前状态

核对日期：2026-11-18。**0.20.1 的完整 213 组测试、pluginval strictness 5、四份音频回归、限定原生启动检查及发行包校验通过。** 本机入口：`dist/Anyvoc-0.20.1-Windows/Anyvoc.exe`。0.20 及更早冻结包保持原样。[0.20.1 验证记录](VALIDATION-0.20.1.md)与历史证据分开保存。

Anyvoc 已能独立演奏、调音和保存音色，当前优先完善独立版体验。它是原创合成器，**尚未达到完整 Serum 2 功能或声音等价，不支持 Serum 预设**。Windows VST3 已构建，FL Studio 和其他 DAW 仍须分别实测。

## 这次改善了什么

0.20.1 修复了确定的卡音序列：琶音器开启时，note-on → CC64 踏板踩下 → note-off → CC121 重置控制器，此前已松开的键仍留在琶音缓存中。修复让 CC121 清除踏板保持的键，保留实际按下的键、琶音步位置与正常尾音，并继续把控制器重置传给声音引擎。三组新增回归覆盖采样率／块长、Poly／Mono／Legato、后续踏板周期，以及弯音／调制轮复位；修复前 1 PASS／2 FAIL，定向修复后 3 PASS，随后完整 213／213 通过。

它没有改变输入通道及同音高键的合并模型，也不能证明历史间歇性持音观察已经解决。以下为继续保留的 0.20 功能：

| 0.20 范围 | 实现与边界 |
| --- | --- |
| 默认 PLAY 页 | 选音色并显式 LOAD SOUND，再用底部琴键试听；TONE、NOTE SHAPE、SPACE 集中常用控制。SYNTH、FILTER、MOD、FX 保留完整功能，切页不重置声音。 |
| 路由 COPY | 独立复制全部 19 个存储字段到首条完全默认的空行，原行不变，成功一次 Undo。Off、None、旁通或零深度不能单独作为空行判断；满表不覆盖。启用副本会增加一条实际调制。 |
| 按目标批量删除 | 旋钮菜单一次清空来源非 Off 且目标匹配的路由，包括旁通行；保留 Source Off 草稿和其他目标，一次撤销。 |
| 音频侧完整接线 | 32 × 19 = 608 个路由字段形成完整快照；组合操作期间沿用旧图，发布完成后再接收新图，读取不等待编辑器、不重试。仅涵盖路由，不代表整个音色或独立宿主事件同时提交。 |
| 兼容 | 与 0.19 相同的 1,256 个宿主参数、schema 14 和 28 个工厂音色；不新增参数，不改变旧行号的宿主绑定。 |

路由中途被宿主改变或编辑器关闭时，操作停止后续写入，但不会撤回已经发送的值或覆盖宿主状态；需要检查当前接线。详细规则见[路由发布与复制](ROUTE_PUBLICATION.md)，PLAY 控件语义见[界面工作流](UI_WORKFLOW.md)。

## 已有能力与主要缺口

下表概括当前实现范围，交付结论仅限上述实际检查。

| 范围 | 已有能力 | 主要边界 |
| --- | --- | --- |
| 声源 | 三个波表／采样／颗粒振荡器、Sub、Noise；16 复音、1–7 路 Unison | 没有多采样键区、SFZ 或频谱振荡器；采样导入最长 20 秒，变调与插值质量仍需改进。 |
| 波表与 Warp | 每帧 2,048 点、最多 32 帧；绘制、谐波幅相、渐变、导出；双层 Warp 与 FM/PM/AM/RM | 公式工具、更多算法与完整过采样抗混叠未实现。 |
| 滤波与效果 | 双滤波器、低／高／带通、12／24 dB、串并联和声源路由；Drive、Chorus、Delay、Reverb | 更多滤波模型、效果种类和效果总线未完成。 |
| 四条包络 | Delay/Attack/Hold/Decay/Sustain/Release、曲率、BPM、Legato 重触发；可拖节点 | Amp 决定声部寿命，其余包络不延长已经结束的声部。 |
| 十个 LFO | 基础波形、Random、33 点 Custom、Lorenz/Rössler；Free/Trigger/Envelope、Swing、20–1,000 Hz Audio Rate | Random 与 Chaos 不使用 Phase/Direction；高速不等于全面抗混叠。 |
| 曲线工具 | 网格、吸附、选区、翻转、位移缩放、数值 SET、复制粘贴和 `.anycurve` | 仍为 33 点、参数精度 0.01；工具查看状态不写入音色。系统剪贴板尚无原生验收。 |
| 调制与宏 | 32 行主来源/AUX、极性、曲率、旁通、移动；八个宏既是来源也是目标，含实时 EV；0.20 增加 COPY、批量删除和整组发布 | 更多声源、滤波和效果目标待增加；EV 是最新活动声部的有效值，不是全局平均值。 |
| 演奏与音色管理 | Poly/Mono/Legato、Glide、轮控、踏板、基础琶音器；28 音色、搜索收藏、`.anyvoc` 保存、撤销 | MPE、Clip、完整元数据管理未实现；琶音器尚无宿主小节相位锁定，输入通道与同音高键的所有权合并。 |
| 界面与平台 | 可缩放界面、PLAY 和完整编辑页；Windows 独立版、VST3 | 完整中文化、无障碍、macOS/AU/AAX 未完成；DAW 工作流待实测。 |

## 接下来先做什么

1. 推送后单独记录 0.20.1 提交的 CI，保留冻结发行包；不借用 0.20 绿色状态。
2. 扩大多声源与多素材的重启恢复检查，继续缩减间歇性琶音问题；单个 CC121 修复不等于所有踏板、通道和重叠音符都已解决。
3. 测量复杂矩阵、颗粒和高 Unison 的实际回调峰值与掉音。随后扩展明确的调制目标，再推进多采样、频谱声源与效果总线。用户需要 DAW 时先验证 FL Studio。阶段与完成条件见[路线图](ROADMAP.md)。

目前没有外接 MIDI、真人听音或跨 DAW 的验收结论。0.20 单份采样的实际进程重启验证不等于所有外部素材恢复通过；离线平均性能不保证实时无掉音。
