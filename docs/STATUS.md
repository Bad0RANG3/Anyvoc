# Anyvoc 当前状态

核对日期：2026-11-18。当前交付版本为 **0.17.0，Windows x64 独立版与 VST3**：源码、本机验收和发行包完整性复核已完成，P1A 的当前约定范围已交付。0.16.0 是此前已验证并交接到 GitHub 的基线；0.17 提交 `f20c1aa` 的云端干净构建和四套共 175 组测试也已通过，见[云端证据](GITHUB_CI-0.17.md)。

Anyvoc 已经是能够独立运行、演奏、编辑并保存音色的 Windows 合成器，也已生成 VST3 插件。当前交付重点是独立版，以及界面和调音体验。用户最初希望获得完整的 Serum 2 同等体验，**这个目标尚未完成**：Anyvoc 使用自己的界面、状态格式和 DSP，实现范围、声音及兼容性都不能视为与 Serum 2 相同，也不能加载 Serum 预设。

## 功能矩阵

“已完成”仅表示该行列出的范围已实现并有验证；“部分完成”表示有可用实现，但仍缺少相关能力；“未实现”不包含仅有设计的内容；“未验证”表示尚无足够的实际使用证据。

| 功能 | 状态 | 已有能力与边界 |
| --- | --- | --- |
| 独立版演奏与编辑 | 已完成本轮检查范围 | 可以用屏幕琴键或 MIDI 演奏，调整音色、保存、加载、撤销；0.17 已原生检查新音色选择、屏幕 C4、Chaos 轨迹与切换、速度撤销和最小窗口。本轮未原生重测保存／加载，设备与驱动组合未全面覆盖。 |
| VST3 与 DAW 工作流 | 部分完成／未验证 | Windows VST3 已构建并通过插件校验；FL Studio 的真实扫描、工程保存重开、自动化及长时间使用仍待验证。当前按用户选择优先使用独立版。 |
| 声源与复音 | 部分完成 | 三个振荡器可使用波表、采样或颗粒模式，另有 Sub 和 Noise；支持 16 复音、1–7 路 Unison。没有多采样键区映射、SFZ 或频谱振荡器。 |
| 波表编辑 | 部分完成 | Wavetable Lab 支持每帧 2,048 点、最多 32 帧，波形绘制、谐波 1–1,023 的幅度／相位编辑、帧间渐变和导出。更完整的公式及编辑工具尚未实现；谐波编辑不等于频谱振荡器。 |
| 采样与颗粒 | 部分完成 | 可导入、循环、反向及设置采样根音，并调整颗粒大小、密度和分散；音色状态包含导入素材。导入限制为最长 20 秒、8–192 kHz、单声道或立体声；音高变换和插值质量仍有限。 |
| Warp 与振荡器间调制 | 部分完成 | 双 Warp 槽，Bend+/−、Pulse Width、Sync、Mirror、Fold，以及 FM／PM／AM／RM。算法与路由范围有限，未实现完整的过采样抗混叠方案。 |
| 滤波器 | 部分完成 | 两个滤波器，低通／高通／带通、12／24 dB，串联顺序、并联和声源路由；尚未覆盖更多滤波器模型。 |
| 四条包络 | 已完成当前范围 | Amp、Filter、Env 3、Env 4 均支持 Delay／Attack／Hold／Decay／Sustain／Release，三段曲率、BPM 同步及独立 Legato 重触发。Envelope Lab 可拖动节点并精确输入。Amp 包络决定声部寿命，其他包络不会在 Amp 结束后继续延长声音。 |
| 十个 LFO | 已完成当前范围 | 正弦、三角、锯齿、方波、Random 和 33 点 Custom；速度／节拍、Free／Trigger／Envelope、线性／阶梯插值、Phase、Forward／Reverse／Ping Pong、Swing 跟随和 20–1,000 Hz Audio Rate。Random 保留自身序列，Phase／Direction 对它不生效。 |
| Chaos LFO | 已完成当前约定范围 | 10 个 LFO 均可使用真实 Lorenz／Rössler 方程积分，支持 Free／Trigger／Envelope、Tempo／Swing／Audio Rate，并提供实际 XYZ 轨迹。原生发现的切换／撤销错误连线已修复并复查。Phase／Direction／相位目标对 Chaos 无效；Random 是另一种算法。数值、生命周期、音频及性能证据见 [Chaos 文档](CHAOS_LFO.md)。 |
| 调制矩阵 | 已完成当前范围 | 32 条路由，启用／旁通、正负强度、主来源／辅助来源、各自极性和曲率、排序、复制与拖放；支持 10 个 LFO 的周期／Custom 相位目标，Random 与 Chaos 忽略相位路由。相位反馈使用一采样延迟。高频调制相关路径逐采样更新，不代表所有控制或所有矩阵配置都采用相同更新频率。 |
| 八个 Macro | 部分完成 | 八个独立宏可作为主来源或辅助来源；目前不能把其他调制接入 Macro，其他可调制目标也仍可扩展。 |

| 音色管理与撤销 | 部分完成 | 当前版有 26 个工厂音色，自存 `.anyvoc`，浏览、搜索、类别、收藏和 64 步／128 MiB 上限的撤销历史。作者／标签编辑、多库管理和预录试听自动播放尚未实现。 |

## 0.17 已取得的验证证据

- **175 个测试组全部通过。** 最终 [四套全量测试](ctest-0.17.txt)用时 135.03 秒，其中 Processor 129.80 秒；[详细记录](test-details-0.17.txt)包含 Engine 61、Processor 98、Wavetable 10、Preset Library 6。它们是软件测试组，不是 175 个 DAW 或设备上的测试。初轮失败记录保留在 [初始日志](ctest-0.17-initial.txt)，当前结论以最终全量复测为准。
- **最终 VST3 通过专用校验。** [pluginval 记录](pluginval-0.17.txt)的 strictness 5、随机种子 `0x5f5ab2b` 结果为 SUCCESS；这不能代替 FL Studio 或其他 DAW 的实际验收。
- **旧音频回归逐字节一致。** 同一旧演示在 0.17 重新渲染后与保留的 0.16 参照逐字节相同，见 [独立音频分析](audio-analysis-0.17.json)。这证明该演示及相关回归覆盖下的兼容性，不等于所有可能音色都已穷尽验证。
- **新混沌音频有受控对比。** 同一份报告分析 20 秒、48 kHz／24-bit／双声道演示：前 10 秒 Lorenz、后 10 秒 Rössler，使用相同声部、MIDI、名义速度和增益。最终构建重新生成的新演示与修复前已分析的 PCM 保持同一哈希。整体峰值约 −26.71 dBFS，RMS 约 0.01898，零个 PCM 满幅样本；两段差值 RMS 约 0.01633。整数 PCM 分析不能独立证明编码前浮点缓冲的有限性，数值差异也不等于主观音质或 Serum 等价结论；本轮没有真人听音。
- **预览检查已有记录范围。** 已生成 80 张预览，其中新增的 Lorenz、Rössler、演化轨迹各含标准及最小尺寸，共 6 张逐一检查，未见裁切。自动生成预览及静态图片检查不能代替实际窗口中的操作验收。
- **混沌数值与性能均有证据。** [Chaos 实现与验证](CHAOS_LFO.md)记录独立方程参考、长期有界性、切换与重置、实际音频及相干 XYZ；[性能基准](benchmark-chaos-0.17.txt)覆盖 8 种情形。16 声部／10 个 1,000 Hz Trigger 的离线墙钟／音频时长为 Lorenz 0.605183、Rössler 0.599409；无路由 Rössler 仍为 0.549767，当前未路由也继续积分。离线平均值不能证明实时无掉音。
- **原生操作已按限定范围完成。** 鼠标选择 Butterfly Current，屏幕 C4 在两种 Chaos 下均有绿色电平；Rössler 后撤销回 Lorenz 清零且不残留错误连线；Chaos 下拖动 Phase 后仍为 0，Speed 从 1.80 调到 7.29 后撤销回 1.80；Free 持续演化，Envelope 短音后 XYZ 稳定；切回 Sine 恢复控件再撤销，最小窗口检查完成。Envelope 的原生观察不是整名义周期的测量，精确终点由引擎测试覆盖。退出后恢复原设置并核对 SHA，见 [本机验证记录](VALIDATION-0.17.md)。本轮未原生重测保存／加载；文字搜索因 CUA 未能传递输入，不能记为通过。
- **发行包完整性通过。** Windows 包包含 190 个文件，完整源码包包含 4,580 个文件；CRC、安全且唯一的路径、精确文件集合及逐文件字节一致性均通过。构建与包内的 EXE／VST3 四个 PE 版本均为 0.17.0，包内二进制哈希匹配最终构建。报告 `Anyvoc-0.17.0-PackageVerification.json` 保存在发行包外层，不放入 ZIP。详见 [0.17 验证记录](VALIDATION-0.17.md)；P1A 当前约定范围交付完成。

## 0.16 历史基线

0.16.0 的 schema 12、1,182 参数、24 个工厂音色、162 个测试组及 pluginval 结果保留在 [0.16 验证归档](VALIDATION-0.16.md)。该版本的独立版原生操作、旧音频一致性、74 张预览与发行包完整性检查也是历史证据，不能直接算作 0.17 的验收。

GitHub 基线提交 `43cf082` 已通过云端干净检出、固定 JUCE、Release 构建和四套共 162 组测试，见 [GitHub 交接记录](GITHUB_HANDOFF.md)及其中的对应运行与日志。整理时本机全量复测为 112.05 秒。这些证据仅针对 0.16，不能用来宣称后续 0.17 功能分支已通过 CI 或已发布。

## 尚不能作出的承诺

当前不能承诺完整复刻 Serum 2、导入其音色、与其声音完全一致，或在“各个 DAW”中都能正常使用。Windows VST3 已有产物，DAW 兼容性必须逐个验证；macOS、AU 和 AAX 仍未提供。

高频调制、非线性 Warp 和音高变换仍可能产生混叠。32 条复杂曲线路由、多复音和高 Unison 会增加 CPU 消耗；现有测试不构成所有设备、所有配置下无音频中断的保证。

此前记录的原生 Ctrl 组合键传递问题，以及琶音器配合延音踏板时偶发的 RMS 异常，本轮没有足够证据宣称已修复，应继续保留为待复核事项。

0.17 的 Lorenz／Rössler 已完成当前约定范围的实现、验证与打包交付；本轮未做真人听音、原生保存／加载重测和 DAW 验收；0.17 云端 CI 已通过，范围见[对应记录](GITHUB_CI-0.17.md)。更多绘图工具、宏作为目标及其他未完成项目继续保留在 [路线图](ROADMAP.md)中。完整 Serum 2 目标还包括上表列出的未实现与部分完成项目，不能用当前版本号、参数数量或一次测试通过代表已经达成。
