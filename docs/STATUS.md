# Anyvoc 当前状态

核对日期：2026-11-18。**当前源码为 0.20.3 候选版，完整构建及 220 组自动测试通过，27 例原始浮点声音与旧参考逐字节一致；真实输出设备无法打开，原生演奏和正式实时复测受阻，尚未宣布整版验收或交付。** [0.20.3 验证记录](VALIDATION-0.20.3.md)按分项更新。

已交付的 **0.20.2** 目录仍为 `dist/Anyvoc-0.20.2-Windows/Anyvoc.exe`，原 Windows／源码 ZIP 保持冻结，见[该版记录](VALIDATION-0.20.2.md)。目录存在不表示当前声卡环境已恢复可用。

Anyvoc 已能独立演奏、调音和保存音色，当前优先完善独立版体验。它是原创合成器，**尚未达到完整 Serum 2 功能或声音等价，不支持 Serum 预设**。Windows VST3 已构建，FL Studio 和其他 DAW 仍须分别实测。

## 这次改善了什么

0.20.3 保留每个路由源原有的共享最近值缓存，再增加 16 个声部槽的精确最近值。曲率主源与 AUX 分开缓存，32 个物理槽不随活动行排序搬动；计算公式、正负零区别、平滑量、累加顺序以及宏／相位反馈不变。详见[缓存合同](MODULATION_CACHE.md)。它不添加参数或预设，也不等于整条回调已经零分配、无锁或实时稳定。

页脚改用构建版本常量，避免新二进制仍显示旧硬编码版本。另修正无设备运行器测试在 Windows junction／路径别名下未命中竞争者注入点的问题；生产运行器不变，旧云端失败保留。

## 已有能力与主要缺口

下表概括当前实现范围，交付结论仅限上述实际检查。

| 范围 | 已有能力 | 主要边界 |

| 声源 | 三个波表／采样／颗粒振荡器、Sub、Noise；16 复音、1–7 路 Unison | 没有多采样键区、SFZ 或频谱振荡器；采样导入最长 20 秒，变调与插值质量仍需改进。 |
| 波表与 Warp | 每帧 2,048 点、最多 32 帧；绘制、谐波幅相、渐变、导出；双层 Warp 与 FM/PM/AM/RM | 公式工具、更多算法与完整过采样抗混叠未实现。 |

## 接下来先做什么

1. 先恢复可用声卡并补齐 0.20.3 原生演奏和六负载三轮回调测量，完成候选包及对应新提交 CI。矩阵缓存已有精确声音回归，但不能在设备受阻时称超预算已解决；随后逐项优化 Chaos／颗粒并覆盖其他缓冲、声卡和 UI 条件。
2. 扩大多声源与多素材的重启恢复检查，继续缩减历史间歇性琶音问题；离线通道回归不等于外接设备与所有输入情形都已验收。
3. 在改善实时可靠性后扩展明确的调制目标，再推进多采样、频谱声源与效果总线。用户需要 DAW 时先验证 FL Studio。阶段与完成条件见[路线图](ROADMAP.md)。

目前没有外接 MIDI、真人听音或跨 DAW 的验收结论。0.20 单份采样的实际进程重启验证不等于所有外部素材恢复通过；离线平均性能不保证实时无掉音。
