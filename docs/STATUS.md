# Anyvoc 当前状态

核对日期：2026-11-18。当前源码为 **0.18.0，Windows x64 独立版与 VST3**。P1B 的 LFO 绘图工具已完成实现、本机自动测试、下述原生检查及发行包核验，**当前约定范围已交付，本地 0.18 包可用；[0.18 云端构建与 188 组测试](GITHUB_CI-0.18.md)通过**。0.17 的 P1A 历史交付继续保留，其提交 `f20c1aa` 的云端干净构建和四套共 175 组测试通过记录见[云端证据](GITHUB_CI-0.17.md)，仅对应当时的 0.17 提交。

Anyvoc 已经是能够独立运行、演奏、编辑并保存音色的 Windows 合成器，也已生成 VST3 插件。当前交付重点是独立版，以及界面和调音体验。用户最初希望获得完整的 Serum 2 同等体验，**这个目标尚未完成**：Anyvoc 使用自己的界面、状态格式和 DSP，实现范围、声音及兼容性都不能视为与 Serum 2 相同，也不能加载 Serum 预设。

## 0.17 已取得的历史验证证据

- **175 个测试组全部通过。** 最终 [四套全量测试](ctest-0.17.txt)用时 135.03 秒，其中 Processor 129.80 秒；[详细记录](test-details-0.17.txt)包含 Engine 61、Processor 98、Wavetable 10、Preset Library 6。它们是软件测试组，不是 175 个 DAW 或设备上的测试。初轮失败记录保留在 [初始日志](ctest-0.17-initial.txt)，当前结论以最终全量复测为准。
- **最终 VST3 通过专用校验。** [pluginval 记录](pluginval-0.17.txt)的 strictness 5、随机种子 `0x5f5ab2b` 结果为 SUCCESS；这不能代替 FL Studio 或其他 DAW 的实际验收。
- **旧音频回归逐字节一致。** 同一旧演示在 0.17 重新渲染后与保留的 0.16 参照逐字节相同，见 [独立音频分析](audio-analysis-0.17.json)。这证明该演示及相关回归覆盖下的兼容性，不等于所有可能音色都已穷尽验证。
- **新混沌音频有受控对比。** 同一份报告分析 20 秒、48 kHz／24-bit／双声道演示：前 10 秒 Lorenz、后 10 秒 Rössler，使用相同声部、MIDI、名义速度和增益。最终构建重新生成的新演示与修复前已分析的 PCM 保持同一哈希。整体峰值约 −26.71 dBFS，RMS 约 0.01898，零个 PCM 满幅样本；两段差值 RMS 约 0.01633。整数 PCM 分析不能独立证明编码前浮点缓冲的有限性，数值差异也不等于主观音质或 Serum 等价结论；本轮没有真人听音。
- **预览检查已有记录范围。** 已生成 80 张预览，其中新增的 Lorenz、Rössler、演化轨迹各含标准及最小尺寸，共 6 张逐一检查，未见裁切。自动生成预览及静态图片检查不能代替实际窗口中的操作验收。
- **混沌数值与性能均有证据。** [Chaos 实现与验证](CHAOS_LFO.md)记录独立方程参考、长期有界性、切换与重置、实际音频及相干 XYZ；[性能基准](benchmark-chaos-0.17.txt)覆盖 8 种情形。16 声部／10 个 1,000 Hz Trigger 的离线墙钟／音频时长为 Lorenz 0.605183、Rössler 0.599409；无路由 Rössler 仍为 0.549767，当前未路由也继续积分。离线平均值不能证明实时无掉音。
- **原生操作已按限定范围完成。** 鼠标选择 Butterfly Current，屏幕 C4 在两种 Chaos 下均有绿色电平；Rössler 后撤销回 Lorenz 清零且不残留错误连线；Chaos 下拖动 Phase 后仍为 0，Speed 从 1.80 调到 7.29 后撤销回 1.80；Free 持续演化，Envelope 短音后 XYZ 稳定；切回 Sine 恢复控件再撤销，最小窗口检查完成。Envelope 的原生观察不是整名义周期的测量，精确终点由引擎测试覆盖。退出后恢复原设置并核对 SHA，见 [本机验证记录](VALIDATION-0.17.md)。本轮未原生重测保存／加载；文字搜索因 CUA 未能传递输入，不能记为通过。
- **发行包完整性通过。** Windows 包包含 190 个文件，完整源码包包含 4,580 个文件；CRC、安全且唯一的路径、精确文件集合及逐文件字节一致性均通过。构建与包内的 EXE／VST3 四个 PE 版本均为 0.17.0，包内二进制哈希匹配最终构建。报告 `Anyvoc-0.17.0-PackageVerification.json` 保存在发行包外层，不放入 ZIP。详见 [0.17 验证记录](VALIDATION-0.17.md)；P1A 当前约定范围交付完成。

## 尚不能作出的承诺

当前不能承诺完整复刻 Serum 2、导入其音色、与其声音完全一致，或在“各个 DAW”中都能正常使用。Windows VST3 已有产物，DAW 兼容性必须逐个验证；macOS、AU 和 AAX 仍未提供。

高频调制、非线性 Warp 和音高变换仍可能产生混叠。32 条复杂曲线路由、多复音和高 Unison 会增加 CPU 消耗；现有测试不构成所有设备、所有配置下无音频中断的保证。

此前记录的原生 Ctrl 组合键传递问题，以及琶音器配合延音踏板时偶发的 RMS 异常，本轮没有足够证据宣称已修复，应继续保留为待复核事项。

0.17 的 Lorenz／Rössler 已完成当前约定范围的实现、验证与打包交付，其云端 CI 证据继续保留。0.18 绘图工具已完成实现、本轮验证与包核验，P1B 当前约定范围已交付，对应提交的云端干净构建与 188 组测试也已通过；操作系统剪贴板、真人听音、外接 MIDI、完整音色原生保存重开和 DAW 验收未由本轮覆盖。宏作为目标及其他未完成项目继续保留在 [路线图](ROADMAP.md)中。完整 Serum 2 目标还包括上表列出的未实现与部分完成项目，不能用当前版本号、参数数量或一次测试通过代表已经达成。
