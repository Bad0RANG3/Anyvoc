# Anyvoc 当前状态

核对日期：2026-11-18。本文描述已完成验证的 **0.16.0**，不把后续设计当作已交付功能。

Anyvoc 已经是能够独立运行、演奏、编辑并保存音色的 Windows 合成器，也已生成 VST3 插件。当前交付重点是独立版，以及界面和调音体验。用户最初希望获得完整的 Serum 2 同等体验，**这个目标尚未完成**：Anyvoc 使用自己的界面、状态格式和 DSP，实现范围、声音及兼容性都不能视为与 Serum 2 相同，也不能加载 Serum 预设。

## 版本快照

| 项目 | 0.16.0 的实际状态 |
| --- | --- |
| 平台与格式 | Windows 64 位独立程序、VST3；未提供 macOS、AU、AAX |
| 工程／音色状态格式 | schema 12；已测试 schema 1–11 的迁移和当前格式的往返保存、非法状态拒绝 |
| 宿主参数 | 1,182 个；包含兼容旧版本所需的隐藏选择器，不代表界面有 1,182 个独立旋钮 |
| 工厂音色 | 24 个；0.16 新增 Swing Carousel、Phase Lantern |
| 自动化测试 | 最终通过 162 个测试组：Engine 54、Processor 92、Wavetable 10、Preset Library 6 |
| 插件校验 | 最终 VST3 通过 pluginval strictness 5 |
| DAW 内验收 | FL Studio 及其他 DAW 尚未完成实际加载、演奏、自动化与工程重开验收 |
| 下一版本 | 0.17 Chaos LFO 仍是设计提案，未进入 0.16 的源码或程序 |

0.16 保留了 0.15 的全部 1,066 个参数定义前缀，在其后追加 116 个参数。旧参数的编号和选项没有因新增功能而重新排列。读取旧状态的兼容测试，不等于旧程序能够读取新格式；请保留旧版音色文件。

## 功能矩阵

“已完成”仅表示该行列出的范围已实现并有验证；“部分完成”表示有可用实现，但仍缺少相关能力；“未实现”不包含仅有设计的内容；“未验证”表示尚无足够的实际使用证据。

| 功能 | 状态 | 已有能力与边界 |
| --- | --- | --- |
| 独立版演奏与编辑 | 已完成当前范围 | 可以用屏幕琴键或 MIDI 演奏，调整音色、保存、加载、撤销；已有原生窗口操作验证。设备与驱动组合未全面覆盖。 |
| VST3 与 DAW 工作流 | 部分完成／未验证 | Windows VST3 已构建并通过插件校验；FL Studio 的真实扫描、工程保存重开、自动化及长时间使用仍待验证。当前按用户选择优先使用独立版。 |
| 声源与复音 | 部分完成 | 三个振荡器可使用波表、采样或颗粒模式，另有 Sub 和 Noise；支持 16 复音、1–7 路 Unison。没有多采样键区映射、SFZ 或频谱振荡器。 |
| 波表编辑 | 部分完成 | Wavetable Lab 支持每帧 2,048 点、最多 32 帧，波形绘制、谐波 1–1,023 的幅度／相位编辑、帧间渐变和导出。更完整的公式及编辑工具尚未实现；谐波编辑不等于频谱振荡器。 |
| 采样与颗粒 | 部分完成 | 可导入、循环、反向及设置采样根音，并调整颗粒大小、密度和分散；音色状态包含导入素材。导入限制为最长 20 秒、8–192 kHz、单声道或立体声；音高变换和插值质量仍有限。 |
| Warp 与振荡器间调制 | 部分完成 | 双 Warp 槽，Bend+/−、Pulse Width、Sync、Mirror、Fold，以及 FM／PM／AM／RM。算法与路由范围有限，未实现完整的过采样抗混叠方案。 |
| 滤波器 | 部分完成 | 两个滤波器，低通／高通／带通、12／24 dB，串联顺序、并联和声源路由；尚未覆盖更多滤波器模型。 |
| 四条包络 | 已完成当前范围 | Amp、Filter、Env 3、Env 4 均支持 Delay／Attack／Hold／Decay／Sustain／Release，三段曲率、BPM 同步及独立 Legato 重触发。Envelope Lab 可拖动节点并精确输入。Amp 包络决定声部寿命，其他包络不会在 Amp 结束后继续延长声音。 |
| 十个 LFO | 已完成当前范围 | 正弦、三角、锯齿、方波、Random 和 33 点 Custom；速度／节拍、Free／Trigger／Envelope、线性／阶梯插值、Phase、Forward／Reverse／Ping Pong、Swing 跟随和 20–1,000 Hz Audio Rate。Random 保留自身序列，Phase／Direction 对它不生效。 |
| Chaos LFO | 未实现 | Lorenz／Rössler 已讨论数值积分方案，但尚无实现、测试或发布。0.16 的 Random 不是 Chaos。 |
| 调制矩阵 | 已完成当前范围 | 32 条路由，启用／旁通、正负强度、主来源／辅助来源、各自极性和曲率、排序、复制与拖放；支持全部 10 个 LFO 的相位目标。相位反馈使用一采样延迟。高频调制相关路径逐采样更新，不代表所有控制或所有矩阵配置都采用相同更新频率。 |
| 八个 Macro | 部分完成 | 八个独立宏可作为主来源或辅助来源；目前不能把其他调制接入 Macro，其他可调制目标也仍可扩展。 |
| 效果 | 部分完成 | Drive、Chorus、Delay、Reverb 可用；尚无完整的多总线效果架构及更多效果种类。 |
| 演奏与琶音器 | 部分完成 | Poly／Mono／Legato、Glide、相位／随机设置、弯音轮、调制轮、延音踏板；基础琶音器支持速率、八度与 Gate，并跟随 BPM，但未实现宿主小节相位锁定。MPE 与 Clip 序列器尚未实现。 |
| 音色管理与撤销 | 部分完成 | 24 个工厂音色，自存 `.anyvoc`，浏览、搜索、类别、收藏和 64 步／128 MiB 上限的撤销历史。作者／标签编辑、多库管理和预录试听自动播放尚未实现。 |
| 界面与易用性 | 部分完成 | 可调整窗口大小，包含波表、包络、LFO 编辑区、调制拖放、强度环与数值输入；仍以英文界面为主，完整中文化与无障碍支持未完成。 |

## 已取得的验证证据

- **测试结果有最终记录。** [验证总览](VALIDATION-0.16.md)、[Engine 结果](engine-0.16.txt)、[Processor 最终复测](ctest-processor-0.16.txt)和[详细测试记录](test-details-0.16.txt)对应上面的 162 个测试组。它们是软件测试组，不是 162 个 DAW 或设备上的测试。[最初的整套测试记录](ctest-0.16.txt)保留了后来已修复的四项 Processor 失败，最终结果以复测记录为准。
- **插件经过专用校验。** [pluginval 记录](pluginval-0.16.txt)验证最终 0.16.0 模块；这不能代替 FL Studio 或其他 DAW 的实际验收。
- **旧音频回归保持一致。** 保留的旧演示在 0.16 重新渲染后与 0.15 参照文件逐字节一致。它证明该演示及相关回归覆盖下的兼容性，不等于所有可能音色都与旧版、其他合成器相同。
- **新增 LFO 控制有独立音频对照。** 20 秒、48 kHz／24-bit／立体声演示分为五段，分别对照 Swing、方向和 Audio Rate。[音频分析](audio-analysis-0.16.json)记录峰值约 −16.16 dBFS、RMS 约 0.02278、零个 PCM 满幅样本，并确认受控段之间存在波形差异。数值分析不能代替主观音质评价，也不能证明与 Serum 2 等价。
- **已有有限的原生界面验证。** 独立版已检查预设加载、LFO 相位拖动、宏拖放、速度模式切换、撤销、琴键发声与读位游标。该人工检查发生在最终连续数值精度修正前，修正后的数值由最终自动化测试覆盖；不将其描述为全部功能都完成了人工验收。
- **发行包已独立核验。** Windows 包与源码包经过 ZIP CRC、路径、文件清单、逐文件字节、版本和哈希检查。报告保留在发行目录外层的 `Anyvoc-0.16.0-PackageVerification.json`，没有放入自身被校验的 ZIP。此次整理文档前，当前生产 `Source` 的 14 个文件与已验证的 0.16 源码包逐字节一致。

GitHub 整理时补充重跑了完整四套自动测试，全部通过，用时 112.05 秒；见 [全量复测](ctest-github-handoff-0.16.txt)和[组别明细](test-details-github-handoff-0.16.txt)。本次没有修改生产合成器代码或已发布二进制。

## 尚不能作出的承诺

当前不能承诺完整复刻 Serum 2、导入其音色、与其声音完全一致，或在“各个 DAW”中都能正常使用。Windows VST3 已有产物，DAW 兼容性必须逐个验证；macOS、AU 和 AAX 仍未提供。

高频调制、非线性 Warp 和音高变换仍可能产生混叠。32 条复杂曲线路由、多复音和高 Unison 会增加 CPU 消耗；现有测试不构成所有设备、所有配置下无音频中断的保证。

此前记录的原生 Ctrl 组合键传递问题，以及琶音器配合延音踏板时偶发的 RMS 异常，本轮没有足够证据宣称已修复，应继续保留为待复核事项。

0.17 的 Lorenz／Rössler Chaos LFO 目前只进入规划。它需要真实动力系统积分、精确参照测试、长期有界性检查和实时性能验证，完成前不会被计入可用功能。完整 Serum 2 目标还包括上表列出的未实现与部分完成项目，不能用当前版本号或参数数量代表已经达成。
