# Anyvoc 0.20.3 候选版使用手册

这是一个原创 Windows 64 位合成器，提供 VST3 插件和可独立运行的程序。它不兼容 Serum 预设，也不承诺声音或功能完全等价。当前优先完善独立版体验，FL Studio 等 DAW 须另行实测。

本轮精确缓存优化保留原调制公式、1,256 个宿主参数、schema 14 和 28 个工厂音色；多通道琶音器、PLAY、COPY 与完整编辑功能继续沿用。最终完整 **220 组通过，218.75 秒**，27 例原始浮点音频与修改前真实参考逐字节一致；最终 pluginval strictness 5 PASS，seed `0x481d1f1`，四份最终演示与冻结 0.20.2 ZIP 全字节一致，宏独立分析 PASS。全部范围见[0.20.3 验证记录](VALIDATION-0.20.3.md)。

## 先听到声音

1. 当前候选自行构建入口为 `build/Anyvoc_artefacts/Release/Standalone/Anyvoc.exe`，页脚应为 0.20.3；候选包尚待校验。已交付旧版入口为 `dist/Anyvoc-0.20.2-Windows/Anyvoc.exe`。收到 Windows ZIP 后请完整解压，再运行其中的 `Anyvoc.exe`，不要在压缩包内启动。以下是正常操作步骤，不代表当前声卡受阻项已经通过。
2. 默认打开 **PLAY**。点 **CHOOSE A SOUND** 或顶部音色名称，搜索 `Northern Lights` 或 `Neon Skyline`，双击结果加载。
3. 用鼠标按底部钢琴键。独立版的 Options / Audio settings 可选择输出设备，推荐 44.1 或 48 kHz、256 或 512 samples。
4. 没声音时先检查电脑音量、输出设备、MASTER 和振荡器 LEVEL。PANIC 可以停止卡住的音符和效果尾音。

## 从 PLAY 开始

**PLAY** 把常用调音放在同一页，和完整编辑页共用声音与撤销历史。先加载喜欢的音色，再按住底部琴键，依次试这三块：

- **TONE**：CUTOFF 调亮暗，RESONANCE 强调截止位置。**ON / OFF** 是 Filter A 的旁通；关闭后保留数值、禁用这两个旋钮。它只影响路由经过 Filter A 的声源，Filter B 和声源接线不随开关改变；没听到变化时可点 **EDIT** 去 FILTER 查看路由。
- **NOTE SHAPE**：Attack 调起音、Decay 调衰减、Sustain 调持音电平、Release 调松键尾音。点 **EDIT** 或包络图进入 Amp Envelope Lab。启用 BPM 后，三个时间旋钮显示节拍分割并禁止无效的秒值编辑，Sustain 仍可调；在 Lab 改分割，关闭 BPM 则回到此前秒值。
- **SPACE**：ECHO 调 Delay 混合量，REVERB 调混响混合量。点 **EDIT** 去 FX 调整完整效果参数。

底部 **GO DEEPER** 的四个入口和顶部页签都能进入完整编辑：

| 入口 | 用途 |
| --- | --- |
| SOURCES / SYNTH | 振荡器、波表／采样／颗粒、音高与音量包络 |
| TONE / FILTER | 双滤波器、串并联和声源路由 |
| MOVEMENT / MOD | 10 个 LFO、4 个包络、32 行调制矩阵 |
| FINISH / FX | Drive、Chorus、Delay、Reverb 与演奏设置 |

切页只改变视图。比如在 PLAY 改 Cutoff，FILTER 会显示同一个值；从任一页 UNDO 都能撤回这次修改。底部两组宏、琴键和 MASTER 始终保留。

想让声音自己变化，点 **MOD SOURCES** 打开来源面板，把 LFO 拖到 PLAY 的 CUTOFF、RESONANCE 或底部宏旋钮。成功投放后面板关闭，仍留在 PLAY；外圈可调深度，MOD 页可查看完整路由。NOTE SHAPE 的 ADSR、ECHO 和 REVERB 不是本版新增调制目标。没有按住琴键的自动持音按钮；先用屏幕琴键或 MIDI 键盘演奏。

0.20 的原生检查确认了上述旁通、跨页 Undo、BPM 显示、调制投放及 1008×684 最小窗口；也确认音色浏览器能打开、C4 有绿色输出。它没有验证从浏览器加载另一音色、真人听音、外接 MIDI 或 DAW，完整范围见[原生记录](ui-play-native-0.20.json)。该会话不是 0.20.2 复测。

## 在 FL Studio 里使用

你已选择先用独立版，下面的插件安装可留待之后进行。

这台电脑的 FL Studio 2025 未发现用户目录中的 VST3，因此请将整个 `Anyvoc.vst3` 文件夹复制到 `C:\Program Files\Common Files\VST3\`，由你在 Windows 提示时确认管理员权限。里面的 `Contents` 目录必须保留；不要只复制其中同名的文件。也可在管理员终端运行随包的 `Install-Anyvoc.ps1 -AllUsers`，脚本会备份已存在的 Anyvoc。

支持用户目录扫描的其他宿主可使用 `%LOCALAPPDATA%\Programs\Common\VST3\`，这台电脑对应 `C:\Users\Bad0RANG3\AppData\Local\Programs\Common\VST3\`。安装脚本不加参数时使用这个无需管理员权限的目录。

打开 FL Studio → **Options → Manage plugins**（部分版本在 File settings 内）→ **Find installed plugins**，启用 Verify plugins。扫描后搜索 **Anyvoc**，将它作为乐器加入 Channel Rack。可以在钢琴卷帘里写 MIDI 音符，也可以连接 MIDI 键盘。

如果当前用户目录没有自动出现在扫描路径中，用 Plugin search paths 左侧的文件夹加号添加该目录，再扫描。这是 [VST3 官方定义的用户目录](https://steinbergmedia.github.io/vst3_dev_portal/pages/Technical%2BDocumentation/Locations%2BFormat/Plugin%2BLocations.html)。

插件向宿主提供的工程状态包含参数、导入／编辑的波表、采样、自绘 LFO、调制路由、演奏设置和音色名称。点顶部 SAVE 生成 `.anyvoc`，用 LOAD 读取。0.20.2 沿用 schema 14 与全部 1,256 参数，可读取 schema 1–13 的旧状态并补默认宏目标字段；28 个工厂音色不增加或重排。琶音器正在按住的键、踏板锁存和步进时钟不写入音色，加载后请重新演奏。请另存新版音色并保留旧文件，不能假定 0.18 或更早程序可读取 schema 14。

完整音色的历史原生 SAVE→INIT→LOAD 证据见 [0.19 原生记录](native-0.19.json)，该次在同一进程内完成。另有 [0.20 真实退出／重启／采样恢复](NATIVE_RESTART-0.20.md)：移走原 WAV、重新启动并 INIT 后手动 LOAD，1256 参数与内嵌采样比较通过；不包含 FL Studio 工程恢复。独立 `.anycurve` 的历史文件操作见 [0.18 验收](VALIDATION-0.18.md)。各记录只适用于当时二进制及明确步骤。

安装步骤参考 [FL Studio 官方手册](https://www.image-line.com/fl-studio-learning/fl-studio-online-manual/html/basics_externalplugins.htm)。Windows VST3 不能装进 Mac 的 Logic；AU/macOS 和 Pro Tools 的 AAX 尚未提供。其他支持 Windows VST3 的 DAW 需要分别实测。

## 找到并收藏音色

点击顶部音色名称或 **BROWSE** 打开 **PRESET LIBRARY**。浏览器打开时，底部琴键仍可试听当前已经加载的声音。

- 输入名字、类别或来源来搜索；多个词以空格分开，结果需同时匹配这些词。支持中文文件名，英文不区分大小写。
- 选择 Factory / User、类别或收藏筛选，按名字或类别排序。单击一行只选中它；双击、按 Enter 或点击 **LOAD SOUND** 才会切换音色。当前已加载的音色有单独提示。
- 点击星标收藏，收藏保存在本机，可跨程序重开使用。星标不会切换音色。收藏文件与工程声音设置分开保存。
- **SAVE** 默认保存到“文档/Anyvoc/Presets”。子文件夹可用来分类，例如 `Presets/My Pads/Warm Sky.anyvoc` 会显示在 My Pads 类别；更深层子文件夹沿用第一层类别。
- 保存后刷新列表。把已有 `.anyvoc` 文件放进这个文件夹，再点 **REFRESH**；浏览器也能打开该文件夹。通过顶部 **LOAD** 可以打开其他位置的音色，但它们不会自动复制进库。
- 只扫描文件名和文件夹，实际加载时才校验音色内容。文件已删除、损坏或版本不支持时，会显示错误并保留当前声音。

工程会保留自存音色名称和声音数据，即使原音色文件之后移走，已保存的工程仍能恢复。收藏按工厂音色名称或用户文件路径识别；移动或重命名用户文件后需要重新收藏。浏览器目前没有自动播放预录试听、作者/标签编辑或多库管理。

## 从零开始调音

从 PLAY 点 **SOURCES / SYNTH** 或顶部 **SYNTH** 进入完整声源页；滤波、调制和效果分别在 FILTER、MOD、FX。

- **WAVE / Position**：在正弦、三角、锯齿、方波之间连续变化；越接近锯齿或方波，谐波通常越丰富。
- **LEVEL**：这个声源的直接音量。B、C 振荡器默认关闭音量；作为 FM/PM/AM/RM 的来源时，LEVEL 为 0 仍可以影响另一振荡器。
- **SEMI / FINE**：半音与微调。把 B 的 SEMI 设为 +12，就比 A 高一个八度。
- **UNISON / DETUNE**：叠加多条稍有偏差的声音，增加宽度与厚度；越多越占 CPU。
- **CUTOFF / RESONANCE**：截止频率与共振。降低低通截止频率让声音变暗，共振强调截止位置。
- **AMP ADSR**：Attack 决定起音快慢，Decay 决定衰减时长，Sustain 决定按住时的音量，Release 决定松开后的尾音。
- **FILTER ENV**：另一条包络，通过 Filter Env Amount 或调制矩阵改变滤波器。
- **MOD**：把顶部 LFO、ENV 或 MACRO 标签拖到 CUTOFF 或振荡器的 WAVE / POSITION 旋钮，即可添加调制。FILTER 页还可拖到两个滤波器的截止、共振及并联平衡旋钮。右键目标查看和编辑已有路由；MOD 页仍可精确设置来源、目标和强度。同一来源重复拖到同一目标会保留原来的强度。
- **FX**：Drive 增加饱和；Chorus 增加层次；Delay 增加重复；Reverb 增加空间。Delay Time 以秒为单位。
- **ARP**：按住和弦自动轮奏；节拍速度跟随 DAW BPM，独立版可用顶部 BPM 设置速度。支持 1/4–1/32、1–3 八度、Gate 长度。

旋钮可拖动、直接编辑数值；双击回默认值（如界面所示）。鼠标停留可查看说明。

## 琶音器的按键、通道和踏板

开启 **ARP** 后，按住的和弦会轮流演奏。0.20.2 分别记录 MIDI 通道 1–16 和音高 0–127：通道 1 和通道 2 的同一个 C4 各占一步，松开其中一个不会松开另一个。顺序先按音高从低到高，同音高再按通道从小到大；演完当前八度后再进入下一八度。超出 MIDI 127 的结果停在 127。

同一通道、同一音高重复收到两次有效按下消息，需要两次配对松开才算完全松键，但仍只占一个琶音位置。后续琶音使用最近一次按下的力度。零力度 note-on 当作松键；没有对应按下的松键会被忽略。生成音符保留来源通道，因此该通道的弯音和调制轮会作用于它，不再统一改到通道 1。

- **延音踏板 CC64**：只保持本通道已松开的键，松开踏板也只释放本通道的锁存。ARP 自己处理踏板；每一步仍按 GATE 的长度结束，不会把所有小音符都拖成长音。
- **重置控制器 CC121**：清除本通道的踏板锁存并复位其弯音／调制轮，仍按住的键保留。其他通道不受影响；只要还有参与琶音的键，步进继续。
- **通道停止 CC120／CC123**：在 Anyvoc 中只清除该通道的按键和锁存，保留该通道的踏板值及其他通道。CC120 立即停止该通道声部；CC123 按正常 RELEASE 结束。这是 Anyvoc 的停止约定，不能把它理解为所有通道的 PANIC。
- **界面 ALL NOTES OFF／PANIC**：全局停止所有通道，清除琶音按键、踏板和时钟；卡音时可直接点击。

普通松键或踏板释放后，如果还有其他键参与，当前这一步会走完原 GATE；所有键都退出时立即开始正常 RELEASE，下次新按键从头起步。切换 Poly／Mono／Legato 会切换引擎声部，但保留 ARP 的按键和时钟，下一步继续。切换 ARP 开关、全局 PANIC、加载／恢复音色、重新准备音频或宿主从播放变为停止会清空琶音运行状态。

这些改变不增加参数或工厂音色，也不等于 MPE、Clip 或宿主小节锁相。完整顺序、控制器及同采样位置事件规则见[琶音器约定](ARPEGGIATOR.md)；外接设备和 DAW 仍须分别验证。

## 直接塑造包络

点 PLAY 的 **NOTE SHAPE → EDIT**、SYNTH 页 **AMP ENVELOPE → EDIT**，或 MOD 包络卡的 **EDIT**，打开 **Envelope Lab**。顶部可切 Amp、Filter、Env 3、Env 4，底部琴键始终可用。

- **DELAY**：按键后等待多久再起音。Amp 的 Delay 大于零时，过早松键可能听不到声音。
- **ATTACK / HOLD**：上升到峰值所需时间，以及峰值保持多久。
- **DECAY / SUSTAIN**：从峰值降到按住琴键时的保持电平。
- **RELEASE**：松键后从当时电平降到零的时间。
- **CURVE**：改变 Attack、Decay、Release 的弯曲程度；0 为直线。正值让变化更多集中在阶段末尾，负值让变化更多集中在前段。

拖动图中节点调整时长或 Sustain，拖动段内曲率手柄改变弯曲程度；下方控件可输入精确值。图上的 **KEY HELD** 平台代表按住琴键，**NOTE OFF** 表示松键位置，平台宽度不是可设定的时长。一次拖动可以用顶部 UNDO 撤回。

开启 **BPM** 后，五个时间阶段使用各自的节拍分割；Sustain 仍为电平。比如 120 BPM 下，1/4 是 500 ms，1/8 是 250 ms。**T** 是三连音，**D** 是附点，**Instant** 跳过该时间段。关闭 BPM 会回到此前保存的秒值；两套设置分别保留。独立版跟随顶部速度，DAW 内优先跟随宿主速度。主卡的同步时间不可用秒旋钮修改，请打开 Lab 调整分割。

启用新阶段、曲率或 BPM 后，演奏中修改时长或速度会改变当前阶段剩余部分的推进速度，不重新起音；修改曲率会立即改变当前电平。新增控制保持默认值时沿用旧版 ADSR 的行为。

**RETRIGGER IN LEGATO** 只影响当前包络：全局 Legato 连奏时，每次新按键仍从头触发这条包络；其他未开启的包络继续运行。松开最后按下的键、回到仍按住的旧音时，不额外重触发。可让音量保持连贯，同时让每个新音重新打开滤波器。

试 **Motion / Clockwork Bloom** 查看按 BPM 运行的保持和衰减；试 **Lead / Second Breath**，按住一个音再按另一个音，比较 Filter 包络的 Retrigger in Legato 开关。鼠标一次点击单键无法单独证明连奏重叠行为，可用 MIDI 键盘或 DAW 中重叠的音符试听。

`Anyvoc-v0.15-Envelopes-Demo.wav` 是 20 秒对比，每段 4 秒：Clockwork Bloom 的直线曲率、原厂曲率、加快至 150 BPM，再是 Second Breath 关闭和开启包络连奏重触发。

## 十个 LFO、四个包络和八个宏

**MOD** 页的两张 LFO 卡可通过标题选择 LFO 1–10；点 **EDIT LFO** 打开绘制面板。十个 LFO 各自保存速度、波形、33 个自绘点、节拍分割、Free / Trigger / Envelope 模式及线性/阶梯插值。切换查看的 LFO 不会改变声音。

右侧包络卡可以切换 **Amp Env、Filter Env、Env 3、Env 4**。Amp 决定声音的起音和结束；其余包络可以独立调制波形、滤波、Warp 等目标。四条包络都可作为矩阵的主来源或 AUX。Mono 会重新触发包络；Legato 默认延续包络进度，也可以逐包络开启 Retrigger in Legato。Amp 结束后，其他包络不会额外延长声音。

底部宏区用 **1–4 / 5–8** 切换四个可见旋钮，共八个宏；切换组只改变查看内容。顶部 **MOD SOURCES** 展开全部来源入口，来源也可在矩阵中直接选择。Macro 1–8 同时是调制来源和可拖放的目标。

先试 **Motion / Prism Weave**：LFO 10 扫描截止频率，LFO 3 改变波形，LFO 4 左右摆动；切到宏 **5–8**，转动 Macro 5 可以调整 Env 3 对 Warp 的作用。再试 **Pad / Four Horizons**：Env 3 让声音缓慢变亮，Env 4 改变波形，Macro 8 控制 LFO 9 的左右摆动深度。

`Anyvoc-v0.14-Sources-Demo.wav` 是 16 秒示例：前两段用 Prism Weave，Macro 5 分别为 0% 和 100%；后两段用 Four Horizons，Macro 8 分别为 0% 和 100%。每段 4 秒。

## 让一个宏带动多项变化

先加载 **Performance / Prism Handle**，按住琴键，转动底部 **MACRO 1**。这个预设用同一个宏改变滤波截止、OSC A 波表位置和第一层 Warp。旋钮的数字是你设定的 **基础值（base）**，宿主自动化和手动操作也只改变这个值。

每个宏下面的 **EV** 是只读的实际有效值：

- **EV: latest voice** 表示最新活动声部实际使用的值，包含连入这个宏的调制。和弦中各音符可有不同值，界面只显示其中最新的活动声部，不是所有声部的平均值；松键后的 release 仍算活动声部。
- **EV: idle base** 表示当前没有活动声部，读数为平滑后的基础值。刚载入音色或 PANIC 尚待音频回调执行时，会先显示当前参数基础值，避免沿用旧声部。
- 八个 EV 来自同一份引擎快照。它们不会转动基础旋钮、写回宿主自动化或产生撤销记录。基础值有 15 ms 平滑，因此调整瞬间 EV 可能短暂与旋钮数值不同。

再加载 **Motion / Breathing Prism**。它将 MACRO 1 的基础值设为 20%，用 Trigger 模式的 0.4 Hz 三角 LFO 1，经 Unipolar 路由以 60% 深度调入 Macro 1。按住琴键时，基础旋钮保持 20%，EV 随 LFO 变化，原来由 Macro 1 控制的三项目标一起运动。松键后可观察 release，等声部结束再看 idle base。

要自己建立这条连接：

1. 从 **Prism Handle** 开始，按需要设置 LFO 1 的 Shape、Rate 和 Play Mode。
2. 将顶部 **LFO 1** 标签拖到底部 **MACRO 1** 旋钮；也可以打开 **MOD SOURCES**，把任意来源拖到可见宏。要使用 Macro 5–8，先切到底部 **5–8** 组。
3. 在 MOD 矩阵找到新行，目标应为 **Macro 1**；需要单向增加时，点 EDIT 把 POLARITY 设为 Unipolar，再调 AMOUNT。矩阵目标列表包含 **Macro 1 … Macro 8**，共 36 个目标选项，原目标的含义保留。
4. 选中这个来源后，上下拖宏的彩色**外圈**调整该路由深度；中心仍调基础值。Shift 可细调，右键可选择路由、旁通或移除。重复投放同一来源到同一目标会保留配置并重新启用匹配行，不额外复制。一次有效编辑可用 UNDO 撤回。

外圈表示选中一条路由的名义范围，不是复音总值或反馈后的实时范围；实际读数看 EV。多条入路相加后，宏的有效值限制在 0–100%。基础值为 0% 不代表有调制入路时 EV 也为 0%。

宏还可用作 **AUX SOURCE**：例如 LFO 2 → Pan，再把 AUX 设为 Macro 1，摆动强度就跟随 Macro 1 的有效值。主来源和 AUX 都读取该声部同一采样的八宏快照。选择 None 则不额外缩放；使用 Original 极性时，宏有效值 0% 关闭该路由、100% 完整放行，其他极性与曲率会改变响应。

允许 Macro 1 → Macro 8、Macro 8 → Macro 1，或宏调自身。每个声部先取“平滑基础值 + **前一个音频采样**的入量”，限制到 0–100%，随后计算新的入量供下一采样使用；这不是一整个音频块的延迟。矩阵行顺序不用于决定反馈的先后。新声部和 PANIC 会清除旧入量；Legato 和 release 延续当前声部状态。移除最后一条有效入路生效后，宏回到平滑基础值。反馈和高速调制可能产生快速变化及混叠，可从小深度开始比较。

宏拖放、外圈 Undo、两组 EV 与最小窗口的历史实测见 [0.19 原生记录](native-0.19.json)。其中的 EV 是观察时刻的读数，不是预设固定值或听音评价；本轮是否复测须以 0.20.2 记录为准。

`Anyvoc-v0.19-Macro-Demo.wav` 是沿用的包内资产名，内容须由当前版本重新渲染；本轮已用 0.20.2 程序在独立验证目录重新渲染。生成和独立分析命令见[构建指南](BUILDING.md)。这是 20 秒、四段各 5 秒的固定示例：

| 时间 | 路由变化 |
| --- | --- |
| 0–5 秒 | Macro 1 基础值 40%，控制截止、波表位置和 Warp，尚无调入宏的路由 |
| 5–10 秒 | 添加 Trigger 三角 LFO 1（0.4 Hz、Unipolar）→ Macro 1，深度 40% |
| 10–15 秒 | 继续添加 LFO 2（1.2 Hz）→ Pan，深度 65%，AUX 为 Macro 1 |
| 15–20 秒 | 添加 Macro 1 → Macro 8（基础值 10%，深度 50%）及 Macro 8 → Macro 1（20%），Pan 的 AUX 改为 Macro 8 |

每段使用相同 C4 音符、基础音色和固定增益，前两段只增加一条宏入路，后两段改变上述路由组合，不能把全部差异归因于单一参数。声音数值差异也不代替真人听音评价。

0.20 的 Legacy／Motion／Chaos／Macro 四份重渲染 WAV 与冻结 0.19 包的对应成员逐字节相同，旧示例另与真实留存 0.19 程序新渲染核对。0.20.1 的独立渲染与冻结 0.20 包比较见[历史记录](VALIDATION-0.20.1.md)。0.20.2 的四份重新渲染 WAV 与冻结 0.20.1 ZIP 对应文件[逐字节相同](demo-compatibility-0.20.2.json)，[独立宏音频分析](audio-analysis-0.20.2.json)也已通过；本轮完整范围见[当前记录](VALIDATION-0.20.2.md)。固定演示的数值回归不代表所有接线或实时硬件负载已经验收，多通道等有意修复的旧行为也不要求复现错误音频。

## 改变 LFO 的运动方式

在 MOD 页选择一个 LFO，点 **EDIT LFO** 打开全宽 **LFO Lab**。大画布用于画曲线，下方控件控制它怎样运行；底部琴键仍可试听。

- **RATE MODE**：Free Hz 使用原来的 0.05–20 Hz；Tempo 使用节拍分割；Audio Rate 使用独立保存的 20–1000 Hz。切换模式不会丢掉此前的速度。高速调制会增加谐波，也可能产生混叠并提高 CPU 用量。
- **PHASE**：改变曲线的读取起点，0–360°；演奏中调整不会重新起音。**DIRECTION** 可选 Forward、Reverse、Ping Pong；Ping Pong 的一次完整往返占一个 Rate / Beat 周期。
- **PLAY MODE**：Free 连续运行，Trigger 每次按键重开循环，Envelope 只走一个周期。相位为 0° 时，一次播放的 Forward 停在曲线右端，Reverse 与 Ping Pong 停在左端。
- **FOLLOW SWING**：在 Tempo 模式启用后，跟随下方的全局 Swing 和 1/8 或 1/16 网格。0% 为均分，100% 为 75:25 长短交替。多个 LFO 共享同一个节拍网格，宿主内有 PPQ 时跟随宿主位置；独立版使用自己的连续节拍。
- **Random、Lorenz、Rossler** 没有可寻址的周期波形相位，因此 Phase / Direction 显示 N/A；以前的设置仍保留，切回周期波形后恢复。Chaos 的具体操作见下一节。

可以把一个来源拖到 LFO Lab 的 **PHASE** 旋钮，或在矩阵中选 **LFO 1 Phase … LFO 10 Phase**。强度 100% 代表一整圈，允许正负方向。调制结果在下一个音频采样点应用，因此自己调自己、相互调制都不会形成递归计算；每个复音可以有不同的相位偏移。LIVE 游标显示实际读取位置，START 标记表示设定的起点。相位会绕回一圈，外圈弧线仍只是所选路由的名义范围。

试 **Motion / Swing Carousel**：比较 Swing 0% 和 60%，再切换 Direction。试 **Keys / Phase Lantern**：比较 Audio Rate 110 Hz 和 220 Hz，查看第二行对 LFO 1 Phase 的调制。

`Anyvoc-v0.16-Lfo-Motion-Demo.wav` 为 20 秒、每段 4 秒：Swing 0%、Swing 60%、60% 加反向、Phase Lantern 110 Hz、220 Hz。

## 用 TOOLS 编辑和复用 LFO 曲线

从 0.18 起，打开 **MOD → EDIT LFO**，点击快捷曲线按钮右侧的 **TOOLS**。下半区会换成绘图工具，画布和底部琴键仍可使用；点击同一位置的 **CONTROLS** 返回速度、波形和插值等控制。

- **Draw / Select**：Draw 在画布上绘制；Select 拖出一段闭区间，包含左右两端的点。默认全选，**SELECT ALL** 可重新选中全部 33 点。界面编号 1–33，1 是起点，33 是终点。
- **X GRID / Y GRID**：分别把一个周期、−1 到 +1 的高度分成 1、2、4、8、16 或 32 格。默认 X 为 32、Y 为 4，**SNAP X / SNAP Y** 均关闭；开启后只吸附新绘制的点，不改动已有点。正好处于半格时取右边或上边的位置。Select 不受吸附开关影响。
- **FLIP X / FLIP Y**：只作用于选区。X 反转选中点的左右顺序；Y 把正负值互换，以 0 为中心。选区外的点保留。
- **POINT / VALUE / SET**：选择第几个点，输入 −1 到 +1 的值，再点 SET 提交。选择点或输入暂存值都不会立刻改变声音，数值输入也不受网格吸附影响。

四个变换数值先暂存，点击 **APPLY TRANSFORM** 才一次提交；一次有效操作可用顶部 **UNDO** 撤回：

| 控件 | 作用 |
| --- | --- |
| X OFFSET / POINTS | 在选区内左右移动，范围 −32 到 +32 点；1 点等于一个周期的 1/32 |
| Y OFFSET / VALUE | 在高度缩放后加上此值，范围 −2 到 +2，结果限制在 −1 到 +1 |
| WIDTH / MULTIPLIER | 围绕选区中点缩放宽度，0.25–4 倍，1 为原宽度 |
| HEIGHT / MULTIPLIER | 围绕 0 缩放高度，0–4 倍；0 变平，1 为原高度 |

变换保持选区位置固定，不把点移动到选区外；横向取样越过边界时保持选区端点值，不绕回另一端。只有选区内的值发生变化。APPLY 后暂存数值仍保留，再次点击会把同一变换应用到已经改变的曲线上。

**点值精度仍为 0.01。** VALUE 虽然显示三位小数，提交到现有 LFO 点参数时仍按 0.01 的精度存储，绘图、变换、SET、粘贴和文件载入都遵守这个边界。例如 0.125 写入后约为 0.13，0.0625 约为 0.06，因此细网格上的位置写入后可能略有偏移。文件可表达更精细的小数，但载入后的声音采用实际存下来的点值；再次 COPY / SAVE CURVE 导出的是这些实际值。

**COPY CURVE / PASTE CURVE** 可以跨 LFO、跨插件实例复用整条曲线。**SAVE CURVE / LOAD CURVE** 使用独立的 `.anycurve` 文件，最多 16 KiB。两种方式都只包含全部 33 点和 Linear / Step 插值；不包含选区、网格、速度、BPM、播放模式、相位、方向、调制路由或完整音色。SAVE CURVE 不等于顶部保存 `.anyvoc` 音色的 SAVE。无效或过大的曲线会显示错误并保留当前声音。

粘贴和载入是明确的整条资产替换，忽略选区，并切到 **Custom**。即使点值恰好等于当前 Sine 等基础波形的采样点，或等于 Random 保存的旧自绘点，也会选择 Custom，并形成一次可撤销的声音编辑；连续的基础波形不等同于 33 点插值。已经是 Custom 时重复粘贴或载入相同实际数据，不增加撤销记录。与此不同，没有实际变化的 FLIP、SET 或 APPLY 会保留当前波形，也不增加记录。

对基础波形使用工具时，以当前可见波形的 33 个采样点为起点。Random 的工具页显示 **SAVED CUSTOM CURVE**，操作的是此前保存的自绘曲线，图中不是 Random 的实时输出。Lorenz / Rossler 下可打开工具页，但所有曲线工具禁用；返回 CONTROLS 切换波形后才能编辑。以前保存的点和工具设置仍保留。

选区、Draw / Select、网格与吸附、暂存变换值和工具页开关只属于当前编辑器界面；各 LFO 独立保存这些查看状态，它们不写入音色、工程或曲线文件，也不进入声音撤销历史。COPY / SAVE CURVE 本身不改变声音。等待文件选择时若关闭工具页、切换 LFO 或改变相关声音状态，迟到的载入或保存会取消，请回到当前页面重新操作。

试一次组合编辑：

1. 加载 **Motion / Painted Steps**，打开 **MOD → LFO 1 → EDIT LFO → TOOLS**，选择 **Select**。
2. 在画布上从第 **9** 点拖到第 **25** 点，确认工具栏显示 **SELECTED 9 - 25**。这两端也包含在选区内。
3. 将 **X OFFSET** 设为 **2**、**Y OFFSET** 设为 **0.1**、**WIDTH** 设为 **1.5**、**HEIGHT** 设为 **0.7**。此时只是在准备操作，声音还没有变化。
4. 按住底部琴键，再点 **APPLY TRANSFORM** 比较变化；点顶部 **UNDO** 恢复原曲线。选区和四个工具数值仍保留。
5. 要另存修改后的曲线，先点 **REDO** 恢复编辑，再点 **SAVE CURVE**，使用新文件名如 `Painted Steps Variation.anycurve`。如果在 UNDO 后直接保存，存下的是撤销后的原曲线。

历史真实 SAVE CURVE／LOAD CURVE、Select／Flip Y／Undo、最小窗口和 Escape 取消的记录见 [0.18 验收](VALIDATION-0.18.md)。系统剪贴板的原生跨实例复制粘贴仍须另测；自动测试的内存剪贴板与文件选择器替身不等于操作系统交互已通过。0.20 PLAY、0.20.1 启动检查未重复这组原生文件操作，0.20.2 启动检查也未重复这组原生文件操作。

## 用 Chaos LFO 做持续演化的调制

**SHAPE** 菜单共有八项：Sine、Triangle、Saw、Square、Random、Custom、Lorenz、Rossler。后两项是连续混沌运动，没有固定的重复波形；不会把周期曲线或随机跳点当成混沌轨迹。MOD 主卡和 LFO Lab 使用同一个波形选择，十个 LFO 均可独立设置。

当前 28 个工厂音色中，这两个演示 Chaos：

1. 在 **BROWSE** 搜索并加载 **Motion / Butterfly Current**，打开 **MOD → LFO 1 → EDIT LFO**。它使用 Lorenz、速度 1.80、Trigger，将 LFO 1 连到截止频率和 OSC A 波表位置。按住底部琴键，查看轨迹并听声音怎样变化；试着降低或提高 **EVOLUTION SPEED**，再用 **UNDO** 回到原值。
2. 搜索 **Texture / Spiral Drift**。它使用 Rossler、速度 0.70、Free，调制截止频率与声像。保持发声，打开 LFO 1 的 Lab，对照左右运动和轨迹；切换 Lorenz / Rossler 可比较两种运动，再用 **UNDO** 恢复预设。

Chaos 下的 **RATE MODE** 仍有 Free Hz、Tempo、Audio Rate 三项。这些是沿用的模式名称：普通周期波形以 Hz 表示频率；Lorenz / Rossler 将同一个数值用于控制**演化速度**，不是“每秒重复几次”。Lab 的数值标题改为 **EVOLUTION SPEED**，主卡显示 **SPEED / FAST SPEED**。Tempo 的节拍分割和 **FOLLOW SWING** 也会改变演化速度，但不会让 Chaos 变成每拍完全重复的曲线。关闭某个速度模式后，其原数值仍保留。

**PLAY MODE** 决定何时开始和停止这段运动：

- **Free**：共享的 Chaos 状态持续演化，不随每次按键重置。只要音频引擎继续处理，即使未按琴键，图形也可能继续变化。
- **Trigger**：声部真正重新起音时从该 LFO 的初始状态开始，然后持续演化。它遵循当前 Mono / Legato 的重触发规则；连奏中没有重新起音的音符不会强制重置。不同声部可以处于不同进度。
- **Envelope**：重新起音后运行一个由 Rate / Beat 决定的名义周期，然后保持最后的状态。这是限定演化时长，不表示轨迹绕回起点。音量仍由 Amp 包络控制。

图左侧显示 **X-Y TRAJECTORY**，右侧显示 **X OUTPUT / RECENT SNAPSHOTS**，下方列出归一化的 X、Y、Z 当前读数。X 就是该 LFO 提供给主来源或 AUX 的输出。图形只记录引擎实际发布的点；Free 显示共享状态，Trigger / Envelope 显示最近活动声部的状态，没有活动声部时保持最后读数。

这是界面刷新时取得的近期快照，连续相同的点会被省略，因此各点间的时间间隔不一定相同；横轴不是音频时间刻度，也不是逐采样的完整波形。主卡显示同类的简洁轨迹。切换算法、播放模式或恢复声音状态会清空显示历史，随后从匹配的新读数开始；尚无匹配读数时显示的全零 XYZ 不画成样点，不会把上一种算法的轨迹连到新轨迹。其他静止的非零读数仍会显示，只省略重复点。清空显示本身不会重置或推进声音引擎。实时轨迹不保存到音色文件。

Chaos 下 **START PHASE、DIRECTION、Custom Curve 插值、画布绘制和五个曲线按钮**不可用；相位拖放也不会新建路由。以前的相位、方向、自绘点和已有相位路由仍保留，但相位路由对 Chaos 不产生作用。选择 **Custom** 可继续编辑已保存的自绘曲线；选择周期波形后可重新使用 Phase / Direction。要让 Chaos 改变声音，使用它作为来源调制 CUTOFF、WAVE 或其他有效目标。

`Anyvoc-v0.17-Chaos-Demo.wav` 是沿用的包内资产名，内容为 20 秒对比：前 10 秒 Lorenz，后 10 秒 Rossler，使用相同音符、速度和增益条件。本轮重新渲染与旧版对比的命令见[构建指南](BUILDING.md)；数值分析不能代替真人听音评价。

Chaos 原生历史操作与快照修复见 [0.17 验收](VALIDATION-0.17.md)。当时检查了两算法、Undo、速度、Free、短音后保持和最小窗口，未原生计时完整 Envelope 名义周期；自动测试另验证该周期。这些旧记录不代替本轮实际操作。

## 在矩阵里控制调制

**MOD** 页提供 32 条路由。默认每页 8 条，用左右翻页按钮切换；**EXPAND** 展开全部路由并滚动查看，**COMPACT** 返回。每行 **ON / OFF** 临时旁通但保留设置；**X** 清空整行，UNDO 可恢复。拖最左侧小点手柄调整顺序，展开时拖到边缘会滚动。移动包含全部 19 个存储字段，宿主自动化仍绑定原行号，不自动重排宿主轨道上的自动化片段。

### 复制一条独立路由

1. 在需要复用的行点 **COPY**。详情页也有 COPY；右键目标旋钮，打开某条 **Route** 子菜单，选 **Copy route and edit copy**。
2. 系统从第 1 行开始寻找第一条**完全空行**，复制后定位到副本。列表入口跳到对应页／滚动位置，详情和旋钮菜单入口打开副本详情；原路由保持原样。
3. 按需要修改副本的来源、目标、Amount 或 AUX。副本与原行独立；**启用的副本会立即参与调制**，相同目标的作用会叠加，声音可能马上加强或改变。COPY 不是暂存草稿，不使用系统剪贴板，也不合并同源同目标行。
4. 正常复制算一步历史。复制后尚未继续修改时，一次 **UNDO** 可去掉副本，**REDO** 恢复；后续改 Amount 等操作各有自己的撤销步骤。

“完全空行”要求全部 **19 个存储字段都等于各自默认值**，包括记住但当前未使用的来源／目标选择器。Source Off、目标 None、旁通或 Amount 为零都不单独代表空：只要有非默认值就是占位草稿，不会被覆盖；这样的草稿也可复制。完全默认的来源行没有可复制内容。32 行全占用时提示没有空位，不写入、不增加撤销；另有旋钮或绘图手势未结束时先完成当前编辑。

宿主恢复状态、改动受保护路由，或界面切页／关闭使复制失效时，会停止后续写入；可能提示 **Copy interrupted; review current routes**。这表示需要检查当前路由，不保证自动回滚已发送的部分值，也不会重新寻找另一空槽覆盖宿主的新意图。

### 一次移除某个目标的全部连接

右键目标旋钮，选 **Remove all routes to this target**。它将“实际来源不是 Off 且实际目标匹配”的各行完整恢复默认，旁通行也会清除；**Source Off 的占位草稿保留**，其他目标不变。整次操作算一步 UNDO；没有匹配行时不产生历史。宿主中途改动任一路由会中止后续清空并提示检查当前路由，同样不承诺回滚已发出的值。

复制、移动及上述批量清空会在组合修改结束后向音频发布完整路由图；中途音频沿用上一份完整图。它不保证整个音色同时切换，也不把宿主独立发送的多个自动化事件合并成一次操作。单个连续旋钮手势仍可逐步听到变化；具体适用操作见[路由约定](ROUTE_PUBLICATION.md)。

0.20 独立版已实际操作列表、详情、旋钮菜单三个 COPY 入口；一次 Undo／Redo 能恢复副本，改副本深度不影响原行；四条匹配路由经 Remove-all 清空后，一次 Undo 全部恢复。最小 1008×684 布局可用，详见[原生记录](native-copy-0.20.json)。该记录未原生逐项核对全部 19 字段、满表、最后页复制或宿主中断；这些范围不能从一次成功操作推断，也不标记为 0.20.2 复测。

### 调整每条路由的响应

点一行的 **EDIT** 可分别调整主来源和辅助来源的响应：

- **POLARITY / Original** 保留来源原本的范围：LFO 为 −1 到 +1，包络、力度、调制轮和 Macro 为 0 到 1。**Unipolar** 统一成 0 到 1，**Bipolar** 统一成 −1 到 +1。
- **CURVE** 改变响应的弯曲程度。0% 为直线，正值让变化较晚增大，负值让变化较早增大。图中横轴是输入，纵轴是处理后的值；这是响应曲线，不是实时信号或自由手绘曲线。
- **AUX SOURCE** 用另一个来源乘上主来源，控制调制的强弱。None 等于乘以 1，不改变主来源；选 Macro 1 且使用 Original 极性、零曲率时，其实际有效值为 0 会关闭这条调制，为 100% 会完整放行；若宏本身有调制入路，不能只看基础旋钮。辅助来源也可以有独立极性和曲线；负的辅助值会反转调制方向。
- 最终强度为“处理后的主来源 × 处理后的辅助来源 × AMOUNT”。负 AMOUNT 也会反转方向；旁通后整条路由不参与声音计算。曲线使用指数 `2^(4 × Curve)`，双极信号分别处理正负两侧并保留符号。

可以加载 **Motion / Tide Machine**，打开 MOD 第一行 EDIT，将 AUX SOURCE 选为 Macro 1。按住琴键，逐渐增加底部 MACRO 1，就能从固定音色过渡到 LFO 扫频；把主来源 POLARITY 改为 Unipolar，再调 CURVE，可以改变扫频的范围与变化节奏。重复把同一来源拖到同一目标会保留其设置，并重新开启旁通的匹配路由。

`Anyvoc-v0.13-Matrix-Demo.wav` 是 15 秒示例：每 3 秒依次使用 AUX Macro 1 的 0%、25%、50%、100%，最后一段维持 100% 并把主来源曲线设为 +50%。

来源、极性、曲线、辅助源和旁通切换在下个音频块应用，可能出现突变；AMOUNT 使用现有平滑处理。需要平滑改变调制强度时，优先转动 AMOUNT 或作为 AUX 的 Macro。多条相同目标的路由会相加，旋钮外圈仅显示选中路由的名义范围，并按它的极性与辅助范围计算；旁通时外圈灰显。Macro 1–8 也可作为目标，宏的实际有效值另见底部 EV；32 条复杂曲线路由会增加处理量。

## 直接在旋钮旁调整调制强度

把顶部 **LFO 1** 拖到 **CUTOFF** 或底部 **MACRO 1** 后，旋钮外围会出现一条彩色弧线。按住外圈上下拖动，调整这条路由的强度；旋钮中心仍调整对应目标的基础值。按住 **Shift** 可细调。底部状态栏显示当前来源、目标、矩阵行号与百分比。

- 单击顶部 LFO、FILTER ENV 或 MACRO 标签，会选中这个来源并显示对应外圈。选择标签不会改变声音或新建路由；拖到目标才会分配。
- 往上拖增加深度，往下拖可越过零变成负值、反转调制方向。双击外圈把深度设为 0%，保留路由，之后仍可继续拖动。
- 同一来源连到同一目标有多条矩阵路由时（例如 COPY 后），默认显示第一条。右键目标，进入带 **Route 行号** 的子菜单，选 **Edit this route on the knob**，即可选择其他行；Velocity、Mod Wheel 也可这样选中。外圈只表示当前这一条，不是各路由之和。
- 弧线表示当前路由在基础旋钮范围内的预计变化范围，并不是实时声音分析。LFO 在基础值两侧运动；包络、Velocity、Mod Wheel、Macro 从基础值向一侧运动。滤波截止的变化按倍频计算，其他已支持目标按其参数值相加。
- 其他调制路由、滤波包络、键盘跟踪、播放音高与采样率限制都可能继续改变实际声音；弧线到达旋钮端点后会截住显示。Sample 起点在下一次起音时应用，Warp 仍需选定模式，Parallel Balance 仍只在并联模式生效。
- 一次外圈拖动算一步撤销。松手、Escape、切换来源、关闭面板或窗口会结束这次调整并保留已经调出的值，可用 UNDO 撤回。宿主换工程或改动这条路由时，旧拖动会停止，后续鼠标移动不覆盖新设置。

**MOD** 页仍可输入精确数值和管理全部 32 条路由。Pitch、Level、Pan 是全局目标，当前仅在矩阵中调整，不能把它们误当作某一个振荡器的同名旋钮。

## 调错了，撤回一步

顶部 **UNDO** 撤销最近一次声音修改，**REDO** 恢复刚撤销的修改。鼠标停在按钮上可查看下一步会撤回什么。快捷键为 **Ctrl+Z** 和 **Ctrl+Y / Ctrl+Shift+Z**；正在输入名字、搜索文字或旋钮数值时，快捷键用于编辑文字。

本机已实测鼠标按钮；快捷键处理通过代码测试，但原生自动化未能确认 Windows 组合键输入。若快捷键没有响应，请先用顶部按钮。

- 一次旋钮拖动、一次滤波图拖动、一次 LFO 绘制、一次成功路由 COPY 或按目标批量清空各算一步。切换选项、分配调制、换预设、INIT、加载音色、导入 WAV 和应用波表编辑也可撤回。
- 导入的数据保留在当前会话内，即使原 WAV 或音色文件移走，仍可撤回和重做。普通参数撤销会保留当前正在演奏的音符；撤回预设切换会重新建立声音，请重新按键。
- 撤销后再进行新的声音修改，会清掉后面的重做记录。没有实际改变的操作和失败的导入不会清掉重做。
- 最多保留 64 步，并限制历史保留的数据为 128 MiB；达到限制时移除最早的整步记录。一次操作本身超出容量时仍会生效，但不会保留可误导的旧历史。
- 保存和导出不会撤回磁盘上的文件；搜索、收藏、切换面板、弹琴和 PANIC 不属于声音编辑历史。历史不写入音色文件，重新打开程序后从空历史开始。

DAW 自动化不进入这个历史。如果自动化已改过某条记录涉及的参数，撤销会拒绝覆盖它并清除失效记录；不相关的自动化参数会保留。由宿主恢复工程或选择程序时，也会开始新的历史。

## 单音、连奏与滑音

在 SYNTH 页右侧 PERFORMANCE 区域点 **VOICING**。先加载 `Lead / Ribbon Glide`，用鼠标依次点低音和高音，就能听到音高滑动；连接 MIDI 键盘后，可按住一个音再按另一个音，听连奏的区别。

- **Poly**：同时演奏多个音，最多 16 复音；滑音在此模式下不生效。
- **Mono**：一次演奏一个音，最后按下的音优先；新按键或松键回到仍按住的音时，重新开始包络、触发型 LFO 和采样。
- **Legato**：重叠按键之间保留包络、触发型 LFO 和声源的播放进度；包络 Lab 中开启 Retrigger in Legato 的包络会在新按键时独立重触发。全部松开后再按，重新起音。松开最后按下的键，会回到之前仍按住或被延音踏板保留的音。
- **GLIDE**：从当前音高滑到目标音高的时间，范围 0–2 秒；0 关闭滑音。音高按半音距离平滑变化，相隔半音或八度都使用设定的时间。滑音中再次换音，会从当时的音高继续。
- **ALWAYS**：关闭时只在重叠按键或踏板保留的音之间滑动；开启后，分开弹奏也会从上次音高滑过来。`Ribbon Glide` 默认开启，方便用鼠标试听。

滑音作用于波表、Sub、Sample 和 Granular 的音高，也影响滤波器的键盘跟踪。切换 Poly/Mono/Legato 会清掉当前引擎声部；ARP 关闭时请重新按键，ARP 开启时则保留参与琶音的键与步进时钟，下一步继续。PANIC 可清掉全部音符和效果尾音。单音模式跨 MIDI 通道共用一个声部，尚不是 MPE；这不等于 ARP 合并不同通道的按键记录。

面板下方的 **PHASE** 设置波表振荡器下次起音的位置（0–360°）。**RANDOM** 是从该位置向前随机偏移的范围：0% 固定，100% 可落在整个周期。**RANDOM UNISON** 打开时，主声音使用这个范围，其他叠加声音使用整个周期随机；关闭后，全部叠加声音都使用设置的范围。要让每次起音稳定，可关闭 RANDOM UNISON 并将 RANDOM 设为 0%。这些设置只在重新起音时应用，不会重置正在连奏的相位；Sample/Granular 不使用波表相位控制。

随包的 `Anyvoc-v0.8-Voicing-Demo.wav` 是 12 秒对比，每 3 秒依次为 Poly、Mono、Legato、Legato 加 180 ms 滑音。四段使用同一套声音和重叠音符，方便听出起音和音高过渡的区别。

## 导入自己的波表

每个振荡器在 Wavetable 模式下可读取 WAV 波表。建议单声道，每帧 2048 个采样，最多 32 帧（65536 个采样）；短的单周期文件也支持。导入文件被转换为单声道并嵌入预设/工程，之后移动原始 WAV 不影响音色恢复。导入有独立的谐波降采样表，减少高音区混叠。

## 自己画波表

选 Init 音色，点击 Wavetable 振荡器的 **EDIT** 打开 Wavetable Lab。波形画布可以直接拖画一个周期；切到谐波视图，可以分页调整第 1–1023 阶谐波的强度与相位。每次松开鼠标后更新声音，底部琴键可以随时试听。

- 切换当前帧，或复制、删除帧，最多 32 帧；至少保留 1 帧。每帧固定 2048 个采样。
- 使用正弦、三角、锯齿、方波、噪声或清空按钮作为绘制起点。Normalize 调整当前帧峰值，Remove DC 去掉直流偏移，Invert 翻转，Smooth 平滑周期边界内的相邻采样。
- Morph 在首尾帧之间填入渐变的中间帧。Waveform 模式按波形采样值混合；Spectral 模式分别混合每个谐波的强度和相位。不同帧之间的扫描由振荡器 WAVE 旋钮控制，也可拖入 LFO 调制。
- **TABLE UNDO / TABLE REDO** 可回退或恢复最近 20 次波表操作；一次鼠标拖画算一步。Revert 回到本次打开编辑器时的波表；这些编辑历史只在本次编辑器会话中保留。每次应用也进入顶部全局历史；全局撤销改变了波表时会关闭原波表编辑会话，重新点 EDIT 即可编辑当前版本。
- EXPORT 导出单声道浮点 WAV，每帧 2048 个采样。重新导入 Anyvoc 时保留编辑后的强度；SAVE 音色也会保存全部帧。

谐波叠加可能使峰值超过 1；浮点存储保留这些数值，Normalize 可主动整理音量。编辑后不会自动把每帧都拉到相同音量；播放引擎会去掉直流分量。通用外部波表导入仍默认逐帧归一化。WAV 导出不代表 Serum 预设兼容。

## 谐波强度、相位和频谱渐变

在 Wavetable Lab 内选择 **HARMONICS** 调强度，选择 **PHASE** 调各谐波的起始位置。每页显示最多 64 个谐波，页选择覆盖第 1–1023 阶；最后一页是 961–1023。鼠标停留时可读到具体谐波编号和数值，拖画后松开即应用，一笔只算一步撤销。切换视图、页或渐变模式不会修改音色。

- 相位以正弦为 0°，+90° 对应余弦，范围为 −180° 到 +180°；两端代表同一相位。它逐个调整谐波，与 VOICING 中移动整个振荡器起音的 PHASE 不同。
- 先在 HARMONICS 给某个谐波增加强度，再到 PHASE 修改它。静音谐波的相位没有可听意义，单独画相位不会产生声音，也不会记住供以后使用的隐藏相位。
- 相位重置和随机化只作用于当前页已有的谐波，其他页与各谐波的强度保持不变。调整相位会改变叠加后的波形；不一定像调整强度那样明显改变单个持续音的听感。
- 选择 FROM / TO，并在两端之间保留至少一帧，然后选 **Spectral** 再点 **MORPH**。两端及范围外的帧保持不变，中间帧会被替换。相位沿较短方向过渡；某端谐波静音时，借用另一端的相位。
- 两个等强度但反相的波形，在 Waveform 混合的中点可能相互抵消；Spectral 会保留谐波强度并转动相位。生成中间帧后，实时 WAVE 扫描仍使用现有的线性帧混合。

第 1023 阶接近单周期数据所能表示的最高频率，实际演奏高音时会被抗混叠处理衰减；不保证每一阶都能听到。直流与第 1024 阶的特殊 Nyquist 分量不作为普通谐波编辑，播放时会移除。所有编辑结果随 SAVE 和 EXPORT 保存。

## 把录音变成乐器

振荡器顶部可选 **Sample** 或 **Granular**。导入按钮或拖入 WAV 会读入最长 20 秒的单声道/立体声文件（8–192 kHz），转换为 48 kHz 并保存在音色里。长文件请先裁剪。B、C 仍需调高 LEVEL 才能听到。

- **Sample** 按键播放录音。POSITION 设定下一次按键的起点；ROOT 表示录音原本的 MIDI 音高，默认 60（中央 C；宿主的八度标记可能不同）。LOOP 循环播放，REVERSE 反向播放。
- **Granular** 把录音切成短颗粒叠加。POSITION 可实时扫描取样位置；SIZE 是颗粒长度，DENSITY 是每秒颗粒数，SPRAY 控制随机取样范围。按住一个音再缓慢拖 POSITION，可获得持续变化的音色。
- 打开振荡器详情面板调整这些参数。先选 `Sample / Copper Bell` 或 `Granular / Cloud Bell`，无需导入即可试听原创内置声音。

三个振荡器可以混用三种模式。每个振荡器各保存一份波表和一份采样，切换模式不会丢失导入内容。

## 画出声音的变化

打开 MOD 页，点击 EDIT LFO 1 或 EDIT LFO 2，在大画布上拖动绘制曲线。横向表示时间，纵向表示调制强度；画布使用 33 个控制点，拖动会连起经过的点。曲线自动随音色保存。

- **SYNC** 开启后，速度改用音符时值；T 表示三连音，D 表示附点。关闭后使用 RATE 的 Hz 速度。
- **Free** 连续运行；同步且宿主提供播放位置时跟随宿主拍点。
- **Trigger** 每次按键从曲线开头循环，每个复音独立。
- **Envelope** 每次按键只运行一次，然后停在曲线终点。
- **Linear / Step** 选择控制点之间渐变或阶梯跳变。快捷曲线按钮可作绘制起点。
- 顶部 BPM 在独立版控制 LFO 和琶音器速度；宿主提供有效速度时显示 HOST 并使用宿主速度。播放光标来自合成引擎的实际相位。

先选 `Motion / Painted Steps`，按住琴键，然后打开 LFO 编辑器修改曲线，即可听到滤波变化。

## 两个滤波器怎样配合

点击顶部 **FILTER**。A、B 各有低通、高通、带通选择，独立的开关、截止、共振、包络强度、键盘跟踪和 12/24 dB 斜率。主 SYNTH 页的滤波旋钮控制 A；滤波页面的曲线显示基础参数下的名义响应，包络与调制会在实际演奏中继续改变声音。

- **A > B / B > A**：Both 声源依次经过两个滤波器。可用高通去除低频，再用低通削减高频。24 dB 通过两级同类滤波器形成更陡的截止。
- **Parallel**：Both 声源分别送进 A 和 B，再按 BALANCE 混合；最左只听 A 分支，最右只听 B 分支。A only / B only 的声源也受各自分支的平衡音量影响。关闭某个滤波器时，该分支原样通过，因此并联时也可以混合原声与滤波声。
- **声源路由**：OSC A/B/C、SUB、NOISE 分别可选 Both、A only、B only、Bypass。串联模式下，A only 和 B only 只经过指定的一个滤波器；Bypass 直接绕过两个滤波器，再进入后续效果。把 SUB 设为 Bypass，可以保留低音主体。
- **KEY TRACK**：0% 时截止不随音高改变，100% 时每升一个八度，截止也升一个八度；以 MIDI 60 为参考。
- **ENV AMOUNT**：两个滤波器共享 FILTER ENV 的时间曲线，但各自的调制强度可以不同。LFO 和 Macro 还可独立控制 B 的截止、A/B 共振及并联平衡。

先选 `Motion / Dual Current` 再打开 FILTER：A 是高通、B 是带包络与 LFO 扫描的低通，SUB 绕过滤波。调 MACRO 1 可增加 B 的共振。旧音色读取时默认 A 开启、B 关闭、所有声源经 Both 串联，保留此前的单滤波路线。

## 叠加两层波形变形

每个 Wavetable 振荡器都可点击 **WARP** 打开 Warp Lab。先选择一种变形，再增加 AMOUNT；两层按 **Warp 1 → Warp 2** 的顺序处理。上方叠加显示原始波形和经典 Warp 的基础处理结果；它是单周期预览，不包含实时 FM/PM/AM/RM、LFO 调制或播放音高所用的抗混叠处理。启用跨声源模式时，面板会标注未显示的实时部分，请按琴键试听。

- **Bend + / Bend -**：向两个方向弯曲波形的相位分布，改变谐波结构。
- **Pulse Width**：压缩周期的一部分并拉伸另一部分，可配合 LFO 做脉宽变化。
- **Sync**：在一个基准周期内读取更多次波形，形成硬同步式的音色。
- **Mirror**：逐渐把后半周期变为折返读取。
- **Fold**：折叠超出范围的波形幅度，增加谐波和明亮感。
- **Off** 或 **AMOUNT = 0%**：该层不改变声音。两个槽位可以用相同或不同模式。

将顶部 LFO 或 Macro 标签拖到 Warp 的 AMOUNT 旋钮，可添加调制。MOD 页能精确调整强度，也能把目标改到任意振荡器的任意一层。WARP 处理不会覆盖源波表；EDIT 和 EXPORT 仍编辑/导出原始波表。两层设置及调制一起保存在音色中。

先选 `Motion / Folded Orbit` → OSC A 的 WARP，再按住琴键。LFO 1 扫描第一层，MACRO 1 增加第二层 Fold 强度。当前 Warp 适用于波表模式；切到 Sample 或 Granular 时保留设置并停止应用它们。旧音色读取时两层默认关闭。

随包的 `Anyvoc-v0.6-Warp-Demo.wav` 是 12 秒对比：每 3 秒依次为原声、第一层 Bend +、再叠加 Fold、两层加入 LFO。使用同一音高和音量，关闭滤波与效果。播放中的 Warp 会平滑处理新增的直流偏移，面板单周期预览保留变形本身的形状。

## 用一个声源调制另一个声源

先加载 **Keys / Phase Alloy**，打开 OSC A 的 **WARP**。第一层已经选择 **PM - Phase**，来源是 **OSC B**。按住琴键，转动 AMOUNT；回到主页面调 B 的 SEMI 或 WAVE，会改变 A 的音色。B 的 LEVEL 已设为 0，因此你听到的是它对 A 的影响。**Bass / Vector Steel** 使用 FM，MACRO 1 可以增加金属感。

每层均可选择以下模式，再用 **SOURCE** 选择 OSC A/B/C、SUB 或 NOISE：

| 模式 | 听感与操作 |
| --- | --- |
| FM - Frequency | 声源快速改变播放频率，可产生钟声、金属低音和粗糙的音色。 |
| PM - Phase | 声源移动波形相位，改变来源的音高和波形可以得到不同的谐波。 |
| AM - Amplitude | 声源改变音量；深度 100% 时，零信号的来源会让载波振幅减半。 |
| RM - Ring | 声源与载波相乘；深度 100% 时，零信号的来源使载波静音。 |

- 每个音符使用自己的来源信号，取自来源的 LEVEL、PAN、滤波器之前，包含来源自身的 Warp。多重 Unison 和立体声会平均为单路调制信号，并限制在 −1 到 +1。采样或颗粒也可作为来源，尚未导入文件的来源没有信号。
- 每条连接读取前一个采样的信号。同一振荡器选自己时，面板显示 **SELF FEEDBACK**；A、B 互相调制也可运行。来源音量为 0 时仍会按需要运行，因此可能增加 CPU。
- AMOUNT 同样支持 LFO、包络、Macro、旋钮外圈与撤销；SOURCE 和模式可以自动化，也保存在音色里。切换模式或来源有短暂过渡。经典与跨声源模式在同一槽位中互相替代。
- 当前被调制的目标须为 Wavetable；Sample/Granular 可作来源，但不能在此版本中作为 Warp 目标。来源的滤波器输出和外部音频暂未接入。
- FM 是有符号的线性频率调制；100% 深度对应最多正负 8 倍基频的偏移，再受采样率上限约束。PM 的 100% 对应每单位来源信号移动一个周期。FM 深度降到最后 1% 时会渐回原始相位，避免归零时突跳。这些是 Anyvoc 的定义，不等于 Serum 的算法或强度标尺。

`Anyvoc-v0.12-Crossmod-Demo.wav` 为 15 秒对比，每 3 秒依次听原声、FM、PM、AM、RM。跨声源调制目前没有过采样，激烈调制和高音区仍可能出现混叠。

## 已有能力与边界

当前已有三振荡器波表／采样／颗粒、波形与谐波编辑、双层 Warp、跨声源 FM／PM／AM／RM、Unison、16 复音与单音／连奏／滑音、双滤波器、四条图形包络、十个 LFO、Chaos、曲线 TOOLS 与 `.anycurve`、32 行调制矩阵、八宏来源／目标、四类效果、琶音器、28 个工厂音色、浏览／搜索／收藏、64 步全局撤销、WAV 导入与波表导出、基础 MIDI 和工程状态保存。

0.20.2 保留默认 PLAY、独立路由 COPY、完整路由发布和参数／状态格式，分别处理琶音器各通道的重复按键、最新力度、踏板与控制器；本机完整自动测试、pluginval、离线音频对比、限定原生启动检查以及 Windows／完整源码包逐文件校验已通过。本轮范围见[版本记录](VALIDATION-0.20.2.md)，最终包检查以包外 `dist/Anyvoc-0.20.2-PackageVerification.json` 为准。这不表示路线图 P1C 的所有计划或完整复刻目标完成。功能语义见[琶音器约定](ARPEGGIATOR.md)、[界面工作流](UI_WORKFLOW.md)、[路由约定](ROUTE_PUBLICATION.md)、[宏目标约定](MACRO_TARGETS.md)和[路线图](ROADMAP.md)。

尚未实现：多重采样映射、频谱振荡器引擎、MPE、Serum 预设互通、AU/AAX、完整的可访问性/中文界面。波表仍使用固定 2048 点帧长、最多 32 帧，没有公式编辑；频谱编辑只生成波表，不等同于实时频谱重合成振荡器。琶音器跟随 BPM，但不做宿主小节相位锁定。采样/颗粒的高音移调目前采用插值，未做多级抗混叠。高密度颗粒和高复音可能增加 CPU；请保留工程备份。

0.6 同时修正了延迟缓冲区边界的越界读取，并提高了读指针精度。旧音色参数可以恢复，但启用 Delay 的回声尾音可能与旧版不同；不会保留原来的错误读取结果。

完整复刻目标尚未达成。[Serum 2 官方功能概览](https://static.xferrecords.com/Serum%202%20What's%20New.pdf)还包含多重采样/SFZ、频谱模式、更多 LFO 绘制工具、更广泛的 Warp 来源与目标、效果总线、Clip 编曲和更完整的浏览功能。当前这些方面仍有差距，滤波器模型种类也较少。宏目标按 Anyvoc 明确的反馈规则实现，不能据此声称与 Serum 的声音和调制语义等价。加入 Lorenz / Rossler 不意味着实现了 Serum 的相同算法、声音或所有调制行为。Warp 的波表降采样层选择仅降低部分高频能量，Sync、Mirror、Fold、跨声源及高速 LFO 调制并非完全抗混叠。声音等价、所有 DAW 兼容、macOS/AU 和 AAX 均没有验证证据，不能用本项目测试通过代替这些验收。
