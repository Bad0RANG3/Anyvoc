Windows x64 0.18.0 的最终本机构建、四套自动回归、pluginval、音频对比、预览、下述独立版原生操作及发行包完整性校验已完成。0.18 云端 CI 尚未运行。DAW、真人听音和外接 MIDI 不在本轮已验证范围内。上一版记录见 [0.17 验证归档](VALIDATION-0.17.md)。

## 本版实现及兼容约定

十个 LFO 的 TOOLS 页面提供独立 X/Y 网格和吸附、含首尾的选区、Flip X/Y、位移及宽高变换、单点 SET、整曲线 Copy/Paste 和 `.anycurve` 保存／加载。变换值先暂存，APPLY 才写入声音；网格、选择、工具页与暂存值属于编辑器状态，不新增自动化参数或音色字段。完整规则及严格文件格式见 [曲线工具约定](LFO_CURVE_TOOLS.md)，组合操作见 [使用手册](USER_GUIDE.md)。

继续使用 **33 点、0.01 点值步长、1,192 个参数、schema 13 和 26 个工厂音色**。文件模型可保留 float 精度，导入声音参数时仍量化，不能把 Y 16 等分的 0.125 宣称为声音中精确的 0.125。Paste／Load 明确替换为 Custom，即使原基础波形的可见点相同；普通 Flip／SET／APPLY 若无变化则保留原形状且不新增撤销。Chaos 禁用曲线工具，Random 使用保存的 Custom 点。

[源码兼容核对](source-compatibility-0.18.json)将处理器、引擎和三个声音模型的七个文件与 0.17 提交 `f20c1aab4155d80486f5dd12b20fd0da0d6efcf3` 比较，统一 LF 后逐字节相同。这一版没有修改生产 DSP、参数定义、状态迁移或工厂预设。UI 使用宿主手势和一次操作一次撤销；宿主重入、页面变化和异步文件回复均检查相关状态，避免覆盖之后的操作。

## 独立版原生操作

使用下表哈希对应的最终 EXE 和实际 Windows 窗口，以鼠标／键盘自动化逐步观察；未用离线 PNG 替代原生交互证据。

1. 启动恢复 Lead / Neon Skyline，打开 MOD → EDIT LFO 1 → TOOLS；标准窗口的曲线、工具和琴键均可见。
2. SAVE CURVE 打开实际 Windows 保存对话框，保存到测试目录的 `Native18-Sine.anycurve`。独立读取磁盘文件确认 schema 1、Linear、33 点、1,121 字节，SHA-256 `9fb63204b0531bd337c24e8c16889f28040f9929551002cc5398e67f18936a60`；原 Sine 形状和 Undo 状态未变。
3. Select 模式真实拖选第 9–25 点，选区和标签显示一致；Flip Y 后仅选区翻转，一次鼠标 Undo 恢复原 Sine。
4. LOAD CURVE 经实际 Windows 对话框读取刚保存的曲线，回 CONTROLS 确认 Shape 为 Custom。屏幕 C4 点击出现绿色输出表；一次 Undo 恢复 Sine。这没有进行真人听音。
5. 实际拖动窗口至最小内容尺寸 **1008×684**，工具、状态、画布和琴键完整可见。LOAD 后按 Escape 取消，提示取消，曲线、选区和未激活的 Undo 状态不变。
6. 关闭本轮实例并确认无窗口／进程残留，再恢复原 `Anyvoc.settings`；恢复前后 SHA-256 均为 `5000f1074d6b885621afabb357a32e2ba2050f8661ad38c3fb92bc520674ab7e`。未修改实际系统剪贴板或覆盖用户音色。

本轮未原生验证跨实例系统剪贴板、外接 MIDI、每个 LFO 的每种鼠标手势、完整 `.anyvoc` 音色保存重开或 DAW。自动化对这些对应逻辑的测试须与原生范围分开理解；不能将专项人工用例 T01–T10 全部标为通过。
