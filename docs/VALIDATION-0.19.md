## 实现与兼容范围

目标 28–35 分别对应 Macro 1–8；旧目标 0–27、全部旧来源 ID 和宏基础旋钮含义保留。32 行各追加 `MacroEnabled`、`MacroTarget`，因此共 **1,256 个宿主参数、schema 14、28 个工厂音色**。前 1,192 个参数定义和顺序与 0.18 基线提交 `45578ca2f770b21c99ec9aec59a3d9a0b0fc38e1` 在统一换行后逐字节相同，见[参数前缀核对](parameter-prefix-0.19.json)。该核对仅证明定义前缀，运行时接线和迁移另由自动测试验证。

每个声部独立计算 `clamp(本采样平滑基础值 + 前一采样入量, 0, 1)`；所有主来源和 AUX 同时读取这八个有效值，再统一写入下一采样的结果。新音符、抢音、Mono retrigger 和 reset 清除反馈；Mono legato、踏板保持与释放阶段沿用当前声部状态。没有有效入路时直接回基础值，不能遗留旧入量。基础值不被 DSP 反写，EV 是最新实际采样过的活动声部读数；无此声部时显示 idle base。空缓冲区或块末 MIDI 刚建立、但尚未读取来源的新声部不会冒充已采样读数。

来源与 AUX 的极性、曲率、相乘、Amount 平滑保持原合同；受调宏及经过 LFO 相位的相关音高、声像、滤波和 Warp 控制按采样更新。完整规则见 [宏目标约定](MACRO_TARGETS.md)。

## 构建与自动回归

本机使用 Windows x64、MSVC、Windows SDK 10.0.26100.0 和固定 JUCE 8.0.12；构建保留类型转换、JUCE 弃用等既有警告，不宣称零警告。[配置记录](configure-0.19.txt)、[生产目标构建](build-0.19-production.txt)、[测试目标构建](build-0.19-tests.txt)及[声音修复后的完整构建](build-0.19-final.txt)保留原始输出。

[首轮 CTest](ctest-0.19-initial.txt)用时 **189.59 秒**，共 201 组中 200 通过、1 失败。失败在旧 `Advanced matrix source curves, polarity and nominal ranges` 测试：非法目标的夹取预期仍写死为 27，而新有效上限是 35。修正了这个明确的旧上限断言，其他条件保持严格；没有放宽数值容差。首轮七组新引擎测试均已通过。[首轮逐组记录](test-details-0.19-initial.txt)保留失败事实。

静态复核还发现一项真实缓存缺陷：删除“宏 → LFO 相位 → 声音目标”连线时，前一采样的相位入量仍应消费一次；若只刷新这一采样，第二采样已经清除的相位可能仍被声音控制缓存保持到下一个 16 样本控制刻度。修复将退出刷新保留两采样，分别处理最后的延迟读数和其清除值。独立回归在非控制刻度删除相位 AUX 连线，核对这两采样的实际声像，不借用生产路由算法生成期望。

上述修复后，[完整 CTest](ctest-0.19-final.txt)退出码 0，**四套共 201 组全部通过，用时 192.89 秒**；[完整逐组明细](test-details-0.19-final.txt)记录每组结果。此完整运行在后述两处显示文字修复之前。

## 宏路径性能

在 **AMD Ryzen 7 9800X3D、8 核／16 线程**上，确认预览进程退出、没有其他构建／测试重任务后单独运行 `AnyvocEngineTests --benchmark-macros`。完整输出见[原始性能记录](benchmark-macros-0.19.txt)。退出码 0，独立解析确认四配置各三轮、共 12 条测量、2 秒分母和全部中位数一致，checksum 为 0.039300。

固定条件：Release、48 kHz、256 样本块、16 个错峰起音且力度不同的持续声部、32 条有效路由、一个 wavetable 振荡器、unison 1、FX 关闭；仅最后配置打开双滤波。每轮计时渲染精确 2 秒，共三轮并轮换配置顺序。计时包含每块 `setSettings`、渲染和快照发布，不包含实例构造、16 次起音及随后 48 块预热。

## 已知边界与交付状态

- **行移动的完整快照条件：** 引擎在相邻两次 `setSettings` 看见完整 32 行配置的纯置换时迁移平滑状态，并规范宏影响目标的求和顺序。处理器目前逐参数发布、逐原子读取；若音频块恰好读到 UI 多字段移动的中间状态，会先得到非置换配置，不能保证之后恢复为与未移动时逐位一致。音频侧路由整组原子发布列为后续事项。本次精确重排测试覆盖完整前后快照，不冒充并发提交中途也成立。与宏无关的旧目标保留原槽位浮点累加顺序，也不承诺其换行后的逐位一致。
- **反馈与负载：** 单采样反馈可以形成高频变化；限幅保证有效宏值范围，不代表消除混叠。高速、非线性和反馈的抗混叠，以及更广泛实时性能测量仍待继续。
- **范围：** 更多声源／效果参数作为目标、路由复制及 P1C 其余内容仍在[路线图](ROADMAP.md)。既有更多滤波器、频谱振荡器、多采样／SFZ、效果总线、Clip、MPE 等计划未因宏功能而变成已完成。
- **宿主与平台：** 用户当前优先独立版，FL Studio 及其他 DAW 仍待实测；没有据此提供 macOS、AU、AAX 或 Serum 预设兼容承诺。
- **云端：** 0.19 本机包交付已通过，云端 CI 尚待推送后运行。0.18 包和其[云端记录](GITHUB_CI-0.18.md)保留为历史证据，不作为 0.19 的云端通过证明。

本轮交付限定于宏作为目标的当前约定范围；更多 P1C 功能和前述未实测项目继续保留。发行二进制与 ZIP 留在本地 `dist/`，本阶段没有创建或上传 GitHub Release 二进制附件。
