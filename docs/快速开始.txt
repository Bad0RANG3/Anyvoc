  BROWSE 搜索 Performance / Prism Handle，双击加载，按住琴键。
  转底部MACRO 1：一个宏同时控制截止、OSC A波表位置和第一层Warp。
  旋钮数字是你编辑的基础值base；下方EV是实际有效值，不会反写旋钮或自动化。
  EV: latest voice表示最新活动声部，包含release；和弦各音可不同，不是平均值。
  EV: idle base表示没有活动声部，显示平滑基础值；基础值有15ms平滑。
  载入或PANIC尚待音频回调时先显示当前参数基础值，避免留下旧声部读数。

  再试 Motion / Breathing Prism：基础值20%，Trigger三角LFO 1以0.4Hz运行，
  Unipolar、60%深度调入Macro 1；按住琴键，旋钮仍20%，EV和三项声音目标一起变化。
  松键后仍可能有release，等声部结束才显示idle base。

  自己接线：从Prism Handle开始，把顶部LFO 1拖到底部MACRO 1旋钮。
  也可用SOURCES选来源；底部1–4 / 5–8切换八个宏的两组，换组不改声音。
  MOD矩阵目标可选Macro 1–8；EDIT里选Unipolar使LFO只向上增加，再调AMOUNT。
  选中来源后拖宏外圈改路由深度，中心仍调基础值；Shift细调，右键管理路由。
  重复投放同一来源和目标会保留设置并重新启用，不复制新行；UNDO撤回有效编辑。
  外圈只是当前一条路由的名义范围，实际值看EV。入路相加后限制在0–100%。
  基础旋钮0%并不代表有调制入路时EV也是0%。

  AUX例子：LFO 2→Pan，AUX SOURCE选Macro 1，左右摆动跟随宏的实际有效值。
  Original极性下EV为0%关闭该路由，为100%完整放行；None不额外缩放。
  可把Macro 1接到Macro 8，再将Macro 8接回Macro 1；各声部独立计算。
  每采样先用平滑base加前一采样入量，再计算下一采样；不是延迟一整音频块。
  新声部/PANIC清入量，Legato和release延续；最后有效入路删除生效后回到base。
  反馈和高速调制可能剧烈变化或混叠，可从小深度开始比较。

  Anyvoc-v0.19-Macro-Demo.wav的生成方法见BUILDING.md；最终重渲染后的独立PCM分析已通过。
  四份WAV哈希与文字修复前相同，旧示例与0.18程序新渲染逐字节相同；Motion/Chaos哈希也一致。
  20秒分四段，每段5秒：
  0–5秒：Macro 1基础40%，三条出路控制截止、波表位置和Warp。
  5–10秒：增加Trigger三角LFO 1→Macro 1，0.4Hz、Unipolar、40%深度。

试 LFO 绘图工具（0.18已有）：
  加载 Motion / Painted Steps → MOD → LFO 1 的 EDIT LFO → TOOLS。
  TOOLS替换下半区控制，画布和琴键仍可用；CONTROLS返回速度、波形和插值控制。
  Draw在画布绘制；Select拖出包含两端点的选区。默认全选；SELECT ALL重选33点。
  X GRID / Y GRID独立设置1/2/4/8/16/32格，默认32/4；SNAP X/Y默认关闭。
  开启吸附只影响新绘图，不改变旧点；半格位置取右边/上边。Select不受吸附影响。
  FLIP X反转选区左右顺序；FLIP Y以0为中心反转正负。选区外保留。

  组合示例：选Select，从第9点拖到第25点，确认SELECTED 9 - 25。
  设置X OFFSET=2、Y OFFSET=0.1、WIDTH=1.5、HEIGHT=0.7，再点APPLY TRANSFORM。
  X按点位移，1点=1/32周期；WIDTH围绕选区中点，HEIGHT围绕0。
  Y在高度缩放后相加，结果限制在-1到+1；越过选区边界时保持端点，不绕回。
  一次APPLY是一次有效声音编辑；暂存的四个数值仍保留，再点会继续变换。
  用琴键比较，再点顶部UNDO撤回；选区和工具数值不随声音撤销。
  要另存修改后的曲线，先REDO，再SAVE CURVE为 Painted Steps Variation.anycurve。
  若UNDO后直接保存，保存的就是撤销后的原曲线。

  POINT选第1–33点，VALUE输入-1到+1，点SET才提交单点；网格不影响数值输入。
  实际点值仍按0.01精度保存：0.125约为0.13，0.0625约为0.06。
  即使显示三位小数，绘图、变换、粘贴、载入也遵守该精度；细网格可能略有偏移。
  COPY CURVE / PASTE CURVE跨LFO或实例复制整条曲线；忽略当前选区。
  LOAD CURVE / SAVE CURVE使用最多16KiB的独立.anycurve文件。
  曲线文件和剪贴板只带33点及Linear/Step插值，不带速度、相位、路由或完整音色。
  高精度文件写入声音时会量化；再次COPY/SAVE导出实际存值。坏文件会报错并保留声音。
  Paste/Load明确替换整条资产并选Custom；Basic/Random即使点相同，也有一次可撤销编辑。
  已Custom时重复相同数据无新撤销；无变化的FLIP/SET/APPLY也不改变波形或撤销历史。
  基础波形从可见的33点采样编辑；Random工具页编辑SAVED CUSTOM CURVE，不是实时随机输出。
  Lorenz/Rossler可打开TOOLS，但所有曲线工具禁用；回CONTROLS切换波形后再编辑。
  选区、网格、吸附、工具模式和暂存数值只属于当前界面，各LFO独立，不写入音色或曲线文件。
  这些查看操作及COPY/SAVE CURVE都不改变声音。顶部SAVE才是完整.anyvoc音色保存。
  选文件期间关闭工具页、切换LFO或改变相关声音状态，会取消迟到的载入/保存。

找音色与收藏：
  点击顶部名称或 BROWSE 打开 PRESET LIBRARY，输入名字或类别搜索。
  单击只选中；双击、Enter 或 LOAD SOUND 才加载。底部琴键试听当前已加载的音色。
  点击星标收藏，再用收藏筛选快速找到常用音色。
  SAVE 默认存入“文档/Anyvoc/Presets”，可建立子文件夹分类。
  放入新文件后点 REFRESH。顶部 LOAD 也能读取其他位置的 .anyvoc。
  自存音色名称会跟随工程保存；收藏保存在本机，文件改名或移动后需要重新收藏。

试颗粒合成：
  选 Granular / Cloud Bell → 点击 OSC A 的 EDIT → 按住琴键试听。
  CENTRE 改变取样位置，GRAIN SIZE 改变颗粒长度，SPRAY 增加随机变化。
  可以导入自己的 WAV（最长20秒、单声道或立体声）。

没有声音：
  点左上角 Options → Audio settings，选择电脑实际使用的输出设备。
  检查系统音量、MASTER、OSC A 的 LEVEL。
  卡住的音符可用 ALL NOTES OFF 停止。

画声音变化：
  选 Motion / Painted Steps → MOD → LFO 1 卡片的 EDIT LFO。
  在大画布里拖动，画出自己的曲线。按住琴键可试听滤波变化。
  RATE MODE 选 Tempo 跟随顶部 BPM 或宿主速度；Free Hz 使用 RATE。
  Trigger 每次按键从头循环，Envelope 只运行一次，Free 连续运行。
  Linear 是平滑连线，Step 是阶梯变化。DONE 返回。
  曲线和其他参数一起保存在 SAVE 音色里。

Anyvoc-v0.2-Demo.wav 是15秒试听：前5秒铺底，中间5秒采样钟声，最后5秒颗粒。

自己画波形：
  选 INIT → OSC A 的 EDIT，打开 Wavetable Lab。
  在波形画布上拖动；松开鼠标后生效，用底部琴键试听。
  HARMONICS 调整谐波强度，增加高次谐波会使声音更亮。
  PHASE 调每个谐波的相位；先给谐波增加强度，再画相位。0° 是正弦，90° 是余弦。
  页选择可查看第1–1023阶，每页最多64个；高次谐波不一定能在当前音高听到。
  相位重置/随机化只作用于当前页。切页或切视图不会改动声音。
  复制帧后编辑不同波形，再用 WAVE 旋钮或 LFO 扫过不同帧。
  FROM / TO 选两端，之间至少留一帧；选 Spectral 再按 MORPH，会按谐波强度和相位生成中间帧。
  Waveform 是原有波形混合；Spectral 可以避免反相波形在中点完全抵消。
  TABLE UNDO / TABLE REDO 回退与恢复波表操作，REVERT 回到打开时的波表。
  顶部全局 UNDO 改变波表时会关闭旧编辑会话；重新点 EDIT 继续。
  EXPORT 保存 WAV 波表；保存完整音色仍用顶部 SAVE。

这是持续开发中的原创合成器，目前不等同于 Serum 2，也不读取 Serum 音色文件。
你已选择先用独立版；FL Studio 安装与工程重开测试留待之后完成。

试双滤波器：
  选 Motion / Dual Current → FILTER。
  拖 A/B 的 CUTOFF，或拖响应曲线；底部琴键可以随时试听。
  A > B 是串联，Parallel 是并联；并联时 BALANCE 混合两条分支。
  每个声源都能选 Both、A only、B only、Bypass；SUB 的 Bypass 可保留低音。
  关闭滤波器相当于原声通过；并联时仍占用这一条分支。
  将 LFO 1 拖到 FILTER B 的 CUTOFF，可自动扫频；右键旋钮修改强度。
  预设已设置好 LFO 扫描，MACRO 1 控制 FILTER B 的共振。

试两层波形变形：
  选 Motion / Folded Orbit → OSC A 的 WARP。
  每层先选模式，再调 AMOUNT；两层按 1 → 2 的顺序叠加。
  上方曲线显示基础波形变化；底部琴键可以随时试听。
  Bend 弯曲波形，Pulse Width 改变脉宽，Sync 增加周期内重复，Fold 折叠幅度。
  把顶部 LFO 或 Macro 拖到 AMOUNT，可让声音持续变化。
  这个预设的 MACRO 1 已控制第二层 Fold；慢慢向右拖来试听。
  Off 或 AMOUNT 0% 不改变声音；DONE 返回主页面。
  WARP 目前用于 Wavetable，源波表不被覆盖，完整设置用 SAVE 保存。
