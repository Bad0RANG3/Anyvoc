Anyvoc 0.17 独立版 · 三步开始

0.17已完成构建、175组自动测试、pluginval和本机独立版操作检查。
本地打包输出为 dist/Anyvoc-0.17.0-Windows/；完整性以同版本 PackageVerification.json 报告为准。
下述Chaos功能需要0.17；旧版程序不包含。详细验证记录见 VALIDATION.md。

1. 双击 Anyvoc.exe。
2. 点顶部音色名称打开浏览器，搜索 Copper Bell（采样钟声）或 Northern Lights（铺底音色），双击结果加载。
3. 用鼠标按住底部钢琴白键。松开后声音会逐渐结束。

试新的 Chaos LFO：
  BROWSE 搜索 Motion / Butterfly Current，双击加载 → MOD → LFO 1 的 EDIT LFO。
  按住琴键：Lorenz 让截止频率和 OSC A 的波表位置持续变化。
  EVOLUTION SPEED 默认1.80；调慢或调快，比较运动，再用 UNDO 恢复。
  再试 Texture / Spiral Drift：Rossler、速度0.70、Free，让截止与声像演化。
  本次新增这两个音色，共26个工厂音色；原24个仍保留。
  SHAPE 共8项：Sine、Triangle、Saw、Square、Random、Custom、Lorenz、Rossler。
  Lorenz / Rossler 的数值是演化速度，不表示“每秒重复几次”。
  RATE MODE 仍可选 Free Hz / Tempo / Audio Rate；Tempo 和 FOLLOW SWING 改变演化速度。
  Free 持续运行；Trigger 在声部真正重新起音时重开，遵循 Mono / Legato 规则。
  Envelope 按 Rate / Beat 运行一个名义周期后保持，轨迹不必回到起点。
  图左是实际引擎的 X-Y 轨迹，右是近期 X 输出，下方是归一化 XYZ 读数。
  Free 显示共享状态；Trigger / Envelope 显示最近活动声部，没有活动声部时保留读数。
  只记录界面刷新取得的真实快照，连续重复值会省略；横向间距不是均匀音频时间。
  图形不会自行推进声音；切算法、播放模式或恢复音色时清空历史，再积累匹配的新轨迹。
  尚无匹配读数时的全零XYZ不画成样点，不会连入旧轨迹；其他静止非零点仍显示。
  Chaos 下 PHASE、DIRECTION、插值、画布绘制和5个曲线按钮不可用。
  原相位、方向、曲线点及路由仍保存；相位路由在 Chaos 下不生效，也不能向 PHASE 拖放。
  选 Custom 可继续编辑旧曲线，选周期波形后可重新使用相位与方向。
  SAVE 保存声音设置，不保存实时轨迹；0.17新文件需要0.17或更新版本，请另存并保留旧文件。
  Anyvoc-v0.17-Chaos-Demo.wav 是20秒对比：前10秒Lorenz，后10秒Rossler。
  本机已检查两算法实际读数与输出表、速度修改与撤销、Free无按键演化和Envelope短音后保持。
  原生检查未单独计时Envelope完整名义周期；该行为由自动测试验证。
  PCM分析与旧声音对比已完成；尚未完成人耳听音评价、本次原生SAVE/LOAD和DAW实测。

试新的 LFO 运动控制：
  加载 Motion / Swing Carousel → MOD → EDIT LFO。
  将 SWING 从60%调到0%，比较节奏；DIRECTION 可选反向或往返。
  PHASE 改变起点，LIVE 游标显示当前运行位置；调错可以 UNDO。
  FOLLOW SWING 只在 Tempo 模式生效，下方全局 Swing 供所有 LFO 共用。
  再试 Keys / Phase Lantern，Audio Rate 在110和220 Hz之间比较。
  将来源拖到 PHASE 旋钮可以调制 LFO 相位，矩阵中也能选择该目标。
  Random、Lorenz、Rossler 不使用相位和方向，显示 N/A；切回周期波形后恢复原设置。
  Anyvoc-v0.16-Lfo-Motion-Demo.wav 是20秒试听，每4秒一段：
  Swing关 → Swing60% → 加反向 → 高速110Hz → 高速220Hz。
  历史0.16版能读取更早音色；0.17继续读取0.16及更早音色，旧音色默认不开启Chaos。

试包络编辑器：
  加载 Motion / Clockwork Bloom → SYNTH → AMP ENVELOPE 的 EDIT。
  Envelope Lab 顶部可选择 Amp / Filter / Env 3 / Env 4。
  拖图中节点调整时长或保持电平，拖曲率手柄改变起音和衰减形状。
  DELAY 是起音前等待，HOLD 是峰值保持；SUSTAIN 平台表示按住琴键。
  BPM 开启时各时间用节拍分割，关掉后回到原来的秒值。
  120 BPM 的 1/4 是500毫秒，1/8 是250毫秒；Instant 跳过该时间段。
  想输入精确值，用图下方控件；调错后用 UNDO 撤回一次拖动。
  Lead / Second Breath 示范连奏时滤波包络独立重触发。
  用 MIDI 键盘按住一个音再按另一个，切 Filter 的 RETRIGGER IN LEGATO 比较。
  Anyvoc-v0.15-Envelopes-Demo.wav 是20秒对比，每4秒一段：
  直线包络 → 弯曲包络 → 加快BPM → 连奏重触发关 → 连奏重触发开。

试 LFO、包络和宏：

  右侧包络卡可选择 Amp Env / Filter Env / Env 3 / Env 4。

试调制矩阵：
  加载 Motion / Tide Machine → MOD → 第一行 EDIT。
  AUX SOURCE 选 Macro 1，按住琴键，转动底部 MACRO 1。
  Macro 为0时关闭这条扫频，增加后逐渐放行 LFO 的变化。
  POLARITY 选 Unipolar 会让 LFO 只向一个方向调制；CURVE 改变响应节奏。
  BACK 返回矩阵。ON / OFF 可旁通对比，X 清空一行，UNDO 恢复。
  矩阵共有32行，左右翻页；EXPAND 展开后可滚动，拖最左小点可移动整行。
  已写好的宿主自动化仍跟随行号；排序不会自动移动宿主自动化片段。

试新的金属音色：
  BROWSE 搜索 Phase Alloy，双击加载 → OSC A 的 WARP。
  按住琴键，转动第一层 AMOUNT。来源 OSC B 的 LEVEL 为 0 也能改变 A 的声音。
  DONE 返回；调 B 的 SEMI 和 WAVE，可以改变谐波和金属感。
  再试 Bass / Vector Steel；MACRO 1 可以增加 FM 强度。
  FM 改变频率，PM 移动相位，AM 改变音量，RM 将两个信号相乘。
  SOURCE 选择来源；选自己会显示 SELF FEEDBACK。两层都支持 LFO / Macro 调制。
  上方波形只预览经典变形，不显示实时跨声源调制，请按琴键试听。
  Anyvoc-v0.12-Crossmod-Demo.wav：每3秒依次听原声、FM、PM、AM、RM。

第一次调音：
  CUTOFF：往左拖会让声音更暗。
  AMP ENVELOPE 的 ATTACK：增大后声音慢慢出现。
  RELEASE：增大后松开琴键仍会留下尾音。
  FX 页 REVERB：增加空间感。
  把顶部 LFO 1 拖到 CUTOFF，可以让声音自动变化。上下拖旋钮外圈调强度，Shift 可细调。
  单击 LFO / MACRO 标签查看它的外圈；拖旋钮中心仍调基础值。
  外圈往下可调成负值；双击归零，保留路由。MOD 页仍可输入精确数值。
  一目标多条路由时，右键选 Route → Edit this route on the knob。外圈只代表选中的一条。
  振荡器的 EDIT 打开大面板；DONE 返回。
  SAVE 保存自己的音色，LOAD 读取。INIT 回到初始音色。
  调错后点顶部 UNDO 撤回一步，REDO 恢复。一次旋钮拖动算一步。
  Ctrl+Z 撤销，Ctrl+Y 或 Ctrl+Shift+Z 重做；输入文字时用于文字编辑。
  本机已实测顶部按钮；快捷键若没有响应，请先点 UNDO / REDO。
  换预设、导入声音和画曲线也能撤回，最多64步；重新打开程序后历史清空。
  SAVE / EXPORT 已写入的文件不会被撤销。

试滑音与连奏：
  搜索并加载 Lead / Ribbon Glide，用鼠标依次点低音、高音，听音高滑动。
  SYNTH 页右侧 PERFORMANCE 区域点 VOICING 打开演奏面板。
  Poly 同时弹多个音；Mono 一次一个音并重新起音；Legato 在重叠按键间保持连奏。
  GLIDE 设置滑动用时；ALWAYS 开启后，分开弹也滑音，适合鼠标试玩。
  下方 PHASE 调起始位置，RANDOM 调随机范围；仅用于波表。
  想要稳定起音，关闭 RANDOM UNISON，并把 RANDOM 设成 0%。
  修改相位后重新按键才能生效；DONE 返回。切换演奏模式后也请重新按键。
  Anyvoc-v0.8-Voicing-Demo.wav 是12秒对比，每3秒依次为复音、单音、连奏、连奏加滑音。

找音色与收藏：
  点击顶部名称或 BROWSE 打开 PRESET LIBRARY，输入名字或类别搜索。
  单击只选中；双击、Enter 或 LOAD SOUND 才加载。底部琴键试听当前已加载的音色。
  点击星标收藏，再用收藏筛选快速找到常用音色。
  SAVE 默认存入“文档/Anyvoc/Presets”，可建立子文件夹分类。
  放入新文件后点 REFRESH。顶部 LOAD 也能读取其他位置的 .anyvoc。
  自存音色名称会跟随工程保存；收藏保存在本机，文件改名或移动后需要重新收藏。

试颗粒合成：
  选 Granular / Cloud Bell → 点击 OSC A 的 EDIT → 按住琴键试听。
  CENTRE 改变取样位置，GRAIN SIZE 改变颗粒长度，SPRAY 增加随机变化。

没有声音：
  点左上角 Options → Audio settings，选择电脑实际使用的输出设备。
  检查系统音量、MASTER、OSC A 的 LEVEL。
  卡住的音符可用 ALL NOTES OFF 停止。

画声音变化：
  选 Motion / Painted Steps → MOD → LFO 1 卡片的 EDIT LFO。
  在大画布里拖动，画出自己的曲线。按住琴键可试听滤波变化。
  RATE MODE 选 Tempo 跟随顶部 BPM 或宿主速度；Free Hz 使用 RATE。
  Trigger 每次按键从头循环，Envelope 只运行一次，Free 连续运行。
  Linear 是平滑连线，Step 是阶梯变化。DONE 返回。
  曲线和其他参数一起保存在 SAVE 音色里。

自己画波形：
  选 INIT → OSC A 的 EDIT，打开 Wavetable Lab。
  在波形画布上拖动；松开鼠标后生效，用底部琴键试听。
  HARMONICS 调整谐波强度，增加高次谐波会使声音更亮。
  PHASE 调每个谐波的相位；先给谐波增加强度，再画相位。0° 是正弦，90° 是余弦。
  页选择可查看第1–1023阶，每页最多64个；高次谐波不一定能在当前音高听到。
  相位重置/随机化只作用于当前页。切页或切视图不会改动声音。
  复制帧后编辑不同波形，再用 WAVE 旋钮或 LFO 扫过不同帧。
  FROM / TO 选两端，之间至少留一帧；选 Spectral 再按 MORPH，会按谐波强度和相位生成中间帧。
  Waveform 是原有波形混合；Spectral 可以避免反相波形在中点完全抵消。
  TABLE UNDO / TABLE REDO 回退与恢复波表操作，REVERT 回到打开时的波表。
  顶部全局 UNDO 改变波表时会关闭旧编辑会话；重新点 EDIT 继续。
  EXPORT 保存 WAV 波表；保存完整音色仍用顶部 SAVE。

这是持续开发中的原创合成器，目前不等同于 Serum 2，也不读取 Serum 音色文件。
你已选择先用独立版；FL Studio 安装与工程重开测试留待之后完成。

试双滤波器：
  选 Motion / Dual Current → FILTER。
  拖 A/B 的 CUTOFF，或拖响应曲线；底部琴键可以随时试听。
  A > B 是串联，Parallel 是并联；并联时 BALANCE 混合两条分支。
  每个声源都能选 Both、A only、B only、Bypass；SUB 的 Bypass 可保留低音。
  关闭滤波器相当于原声通过；并联时仍占用这一条分支。
  将 LFO 1 拖到 FILTER B 的 CUTOFF，可自动扫频；右键旋钮修改强度。
  预设已设置好 LFO 扫描，MACRO 1 控制 FILTER B 的共振。

试两层波形变形：
  选 Motion / Folded Orbit → OSC A 的 WARP。
  每层先选模式，再调 AMOUNT；两层按 1 → 2 的顺序叠加。
  上方曲线显示基础波形变化；底部琴键可以随时试听。
  Bend 弯曲波形，Pulse Width 改变脉宽，Sync 增加周期内重复，Fold 折叠幅度。
  把顶部 LFO 或 Macro 拖到 AMOUNT，可让声音持续变化。
  这个预设的 MACRO 1 已控制第二层 Fold；慢慢向右拖来试听。
  Off 或 AMOUNT 0% 不改变声音；DONE 返回主页面。
  WARP 目前用于 Wavetable，源波表不被覆盖，完整设置用 SAVE 保存。
