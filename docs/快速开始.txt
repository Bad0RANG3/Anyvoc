以下保留正常操作步骤，设备恢复后再试听；本版分项证据与待验范围见 docs/VALIDATION-0.20.4.md。

1. 先让它发出声音
使用独立版 ZIP 时，先完整解压，再双击里面的 Anyvoc.exe，不要在压缩包内运行。
启动后默认进入 PLAY。点 CHOOSE A SOUND，选一个音色，再点 LOAD SOUND。
只选中列表中的名字不会换音色，必须加载后再试听。
用鼠标按住底部钢琴白键；松开后，声音会按音色的设置逐渐结束。

2. 如果没有声音
打开独立版的 Options → Audio settings，选择你正在使用的耳机、音箱或声卡输出。
检查系统音量与插件的主音量，再按底部琴键试听。
先用鼠标琴键确认能发声，再连接 MIDI 键盘。

3. 在 PLAY 调整声音
TONE：控制 Filter A（滤波器）。先切到 ON，再试着拖动 CUTOFF 和 RESONANCE。
  CUTOFF 在低通模式下通常越高越明亮；其他滤波类型的变化不同。
  RESONANCE 加强截止频率附近的声音。
  OFF 时这两个旋钮变暗、不可调整；重新 ON 会保留原来的设置。
  如果变化听不出来，点 TONE 的 EDIT，到 FILTER 检查音源是否经过 Filter A。

NOTE SHAPE：控制一个音符怎样开始、保持和结束。
  ATTACK：起音需要多久。DECAY：从最响降到持续音量需要多久。
  SUSTAIN：按住琴键时保持的音量，不是持续时间。
  RELEASE：松开琴键后，声音淡出需要多久。
  如果启用了 BPM 同步，ATTACK、DECAY、RELEASE 显示节拍长度，只能查看。
  此时点 EDIT 修改节拍长度；SUSTAIN 仍可直接调整。

SPACE：ECHO 增减回声，REVERB 增减混响。
  想调整回声间隔或混响空间大小，点 EDIT 进入 FX。

4. 让声音自己变化
先打开 TONE 的 ON，再点 MOD SOURCES，找到 LFO 1。
把 LFO 1 拖到可高亮接收的 CUTOFF、RESONANCE 或底部宏旋钮上。
拖拽时来源面板会收起；按住琴键试听变化。
旋钮中间调整原来的基础值，彩色外环调整当前选中那条调制的深度。
拖外环时按住 Shift 可以细调；想看完整接线，进入 MOD 页面。
NOTE SHAPE、ECHO 和 REVERB 不是这里的拖拽目标。

5. 保存、撤销和深入编辑
点顶部 SAVE，给音色起一个新名字，保存为 .anyvoc 文件；以后用 LOAD 读回来。
调错了点 UNDO 撤销，想恢复刚撤销的操作点 REDO。
顶部 PLAY / SYNTH / FILTER / MOD / FX 都在编辑同一个音色，切页不会重置它。
PLAY 下方 GO DEEPER 也能进入完整页面：
  SOURCES / SYNTH：选择发声音源。TONE / FILTER：调整滤波。
  MOVEMENT / MOD：编辑 LFO、包络和接线。FINISH / FX：调整效果。

6. 琶音器、踏板和多路 MIDI
开启 ARP 后，按住和弦会依次轮奏；速度可跟随宿主或独立版 BPM。
0.20.2 分别记录 1–16 通道的按键和踏板。不同通道的同一个 C4 各占一步，松开一个不会松开另一个。
顺序先按音高从低到高，再按通道从小到大，然后进入下一八度；超出 MIDI 127 停在 127。
同一通道同一音高重复按下两次，需要两次配对松开，仍只占一步；后续琶音用最近一次按下的力度。
零力度 note-on 作为松键，没有配对按下的松键会被忽略。
生成的音符保留来源通道，所以该通道的弯音和调制轮仍作用于它。
踏板 CC64 只保持本通道已经松开的键；每个琶音小音符仍按 GATE 长度结束。
CC121 只重置本通道踏板、弯音和调制轮，保留仍按住的键及其他通道。
CC120/CC123 只停止本通道，保留其踏板值：CC120 立即停止，CC123 按 RELEASE 结束。
如果想全部停止，点界面的 ALL NOTES OFF / PANIC：它清除所有通道的音符、踏板和琶音时钟。
切换 Poly/Mono/Legato 会切换声部，但 ARP 的按键和步进继续；关开 ARP、PANIC、载入音色或宿主停止会清空它们。
完整规则见 docs/ARPEGGIATOR.md。多通道处理不等于 MPE，也不代表外接键盘或 DAW 已经实测。
